# 《基山·背上的目光》：15秒短剧脚本 v0.1

**类型**：上古异兽电影化还原 / 悬疑揭示 / 无人类角色。
**真实来源**：《山海经》“猼訑”条；山中环境、机关式悬念、动物自然行为和拟定旁白为本次改编创作，**非原典事件**。
**目标**：在15秒内让观众依序辨认羊形、九尾、四耳、背上眼四项硬特征；影片内不让神兽凭空变出新器官，不加入喷火、变人、飞行或未记载法术。
**结构**：4个独立叙事镜头，按信息发生顺序设计；最终机位和具体A/B构图待真实角色/场景图检视后由原版视频 Skill 输出。

|---|---|---|---|
| 0–3.5s | 凌晨的基山石坡雾气贴地。一个羊形异兽从雾中缓缓踏上青石，低头嗅地，四蹄踏地有重心，不像漂浮。正面斜角遮住背。 | 山风、碎石，画外声“基山有兽，名为猼訑。” | 羊形与真实四足运动 |

### 旁白全文
“基山有兽，名为猼訑。九尾，四耳。最不可思议的是……眼睛，竟长在背上。”

约三十多字；15秒时间规划为**估计**，未实测配音。正式生成前核验真实语音时长；过载先简化语气与停顿，不擅自删去主要特征。

### 视觉规定
- 写实奇幻、克制古典，不复制扫描出版物的插画整版。
- 故事环境仅在阶段2由 Skill 输出；此稿的青石、薄雾、石坡为合理创作设定。
- 本段没有人类演员，神兽没有台词；旁白是非画内解说人声。
- 禁止用额外角度重复动作充镜头，不允许尾巴重复分叉、耳朵交融、背部眼长在头部。
- 结尾留下平稳可承接的姿态，不自动增加“佩之不畏”的实体法术效果。
