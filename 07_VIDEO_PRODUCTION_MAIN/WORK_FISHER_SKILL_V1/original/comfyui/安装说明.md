# Work-Fisher AI短剧制作全流程：插件包

共7个自定义插件，覆盖20个自定义节点实例、12种自定义节点类型。原工作流共94个节点、42种节点类型。按本机源码核对，包含禁用/旁路分支所用插件。

| 插件目录 | 工作流节点 |
|---|---|
| comfyui-kjnodes | MiniMaxH3MemoryEfficientSageAttentionPatch、INTConstant |
| comfyui-videohelpersuite | VHS_VideoCombine |
| comfyui-minimax-h3-audio-T8 | SolAttnMiniMax |
| ComfyUI-SeedVR2_VideoUpscaler | SeedVR2LoadVAEModel、SeedVR2VideoUpscaler、SeedVR2LoadDiTModel |
| rgthree-comfy | Image Comparer (rgthree)、Fast Groups Bypasser (rgthree) |
| ComfyUI_Comfyroll_CustomNodes | CR Text、CR Prompt Text |
| Goohaitools-comfyui | 忽略多组孤海 |

## 使用方法

1. 关闭ComfyUI，将压缩包内 custom_nodes 下的7个插件目录放进目标ComfyUI的 custom_nodes。已有同名目录请先备份，再选择替换；不要叠放重复版本。
2. 使用目标ComfyUI自身的Python环境，按插件中 requirements.txt 安装依赖。例如：`目标Python -m pip install -r 插件目录/requirements.txt`。本包未安装或更改本机环境。
3. 重启ComfyUI，导入 workflows 内的原始JSON，并重新选择本机模型和输入图片。

## 包含范围与运行条件

- 这是本机插件源码快照，版本见 manifest.json。工作流记录的历史版本可能与本机快照不同，不保证逐版本还原。
- 包含插件自带前端、字体、运行资源、说明及许可证；过滤Git历史、缓存、日志、环境变量文件及rgthree用户配置，保留默认配置。
- 不包含ComfyUI核心、Python环境、依赖wheel、主模型权重或工作流输入图片。插件自身随带的SeedVR2嵌入张量与孤海人脸地标资源仍保留。
- ComfyUI核心需具有 MiniMaxH3ReferenceToVideo、TextEncodeQwenImage21、ComfySwitchNode、ResolutionSelector、ModelAttentionBackend 等节点。目标环境若缺少这些，应处理核心版本，而不是继续寻找同名插件。
- VHS_VideoCombine 在JSON中标记为 comfy-core，但本机实际提供方是 comfyui-videohelpersuite，已据源码归类。
- SolAttnMiniMax 由本机 comfyui-minimax-h3-audio-T8 注册，保留整个插件及其内部依赖。
- SageAttention/SolAttention等加速后端还受目标GPU、Torch、CUDA及相应依赖影响；源码打包不代表这些二进制依赖已齐备。
- 已核查节点源码归属、ZIP完整性与逐文件SHA256；未启动目标ComfyUI、未执行模型推理。
