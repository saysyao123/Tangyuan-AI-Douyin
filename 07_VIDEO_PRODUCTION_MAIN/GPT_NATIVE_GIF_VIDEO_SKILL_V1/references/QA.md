# 逐阶段质量门禁（不可用单一数字指标替代人眼判断）

## Gate 1 源 GIF
- [ ] 文件是真 GIF；原生帧数、每帧时长、总时间有独立回读证据。
- [ ] 全部帧经 GIF disposal 后能正确解码为独立的完整画面。
- [ ] 抽取首、1/4、中间、3/4、末帧：没有网格错切、相邻镜头拼入、整图滚动。
- [ ] 同一角色脸型、发型、衣物、灯具、背景锁定。
- [ ] 无明显多指、手部突然消失、面部扭曲、背景突变。
- [ ] 若不合格：**停止后期处理，重做源动画**。

## Gate 2 补间
- [ ] 输出 120 帧，每一帧与上一帧是合理的时间过渡。
- [ ] 运动幅度合适；人手、脸、遮挡处重点观看是否重影或撕裂。
- [ ] 极端相邻帧差异和大段近重复帧应触发人工检查，而不是自动放行。
- [ ] 若原生帧质量不足，宁可保留稍低帧率、换镜头或重生成，不能凭光流杜撰复杂动作。

## Gate 3 GIF / MP4 文件
- [ ] GIF 实际 120 帧、总时长 5000ms，非滚动拼图，静止背景不发生整体位移。
- [ ] GIF89a、尺寸统一、明确 disposal；非循环动作默认单次播放。
- [ ] MP4 实际 120 帧、`24/1` FPS、`5.000` 秒、H.264/yuv420p。
- [ ] `qa_report.json` 记录来源帧数、补间帧数、输出参数、问题。
- [ ] 清晰度声明准确：图像放大不等于原生高清。
- [ ] 文件真实存在并可播放，提供真实下载路径；不得虚构链接。

## Gate 4 美术/导演
- [ ] 眼神和动作有明确意图、动作不瞎晃。
- [ ] 固定镜头，气质和人物一致，情绪微电影可用。
- [ ] 真实播放不抖动、不滚动、没有明显手部重影。
- [ ] 视觉 QA 只能由实际检视通过，不能由脚本格式检测代替。
- [ ] 配音、音乐、字幕不在 GIF 中；如要求有声成片，必须合成到 MP4 后再验收。

## 失败处理
`SOURCE_REJECTED`：原始帧错切/不完整 -> 重生成。
`FLOW_REJECTED`：补间闪烁/重影 -> 减少动作、优化原生帧；不得盲目提高采样率。
`ENCODE_REJECTED`：GIF 时长、帧数、格式错误 -> 修复编码并重新回读。
`VISUAL_QA_PENDING`：只有文件指标通过，未审完整成片 -> 不声称最终视觉通过。
