# GPT 原生 GIF 动画提示词与生成门禁

## 图像参考锁定
若已有用户认可的动图，必须以其首帧/原动画作为视觉参考。不得擅自更换人物身份、脸型、发型、服装、室内灯具、窗框位置、灯光色温或镜头视角。角色与背景属于「静态资产」，仅允许显式授权的动作元素变化。

## 推荐源动画规格
- 镜头 9:16 竖屏；每帧独立完整，固定裁切。按当次工具 schema 的帧数上限选择完整源帧，不为了数量牺牲清晰度；历史6/30帧是可保留经验，当前会话不保证可单次生成30帧。2026-11-05 Work接口允许2–16帧。禁止一次要求120格超密网格。
- 源 GIF 可低帧率，但要覆盖 **整段五秒动作的真实阶段**。后期光流补间只能填充中间过渡，不允许原始动作跳跃太大。
- 一次只安排简单、连续的动作；本轮原链路复测优先轻呼吸和一次慢眨眼。历史抬手触碰属于需另验遮挡的动作，不作为首次恢复原链路的默认内容。固定镜头，禁止推拉摇移和大幅身体转身。
- 非无缝循环镜头须完整起止，不得无故返回第一帧。

## 下一轮原生微动复测模板（待原生GIF实测）

以下是依据已发现的手部风险收敛后的候选提示词，状态为 `PENDING_NATIVE_GIF_RETEST`；尚未取得新的原生GIF，不视为已验证生成能力。只有当次原生GIF工具确实启用时执行，参数按其schema设置。例如上限16时可尝试16帧×310ms，先核验真实返回文件，再重定时至最终5秒。

生成真实动画GIF，每帧是一幅完整、固定裁切的画面。沿用已确认的雨窗前人物参考，锁定身份、五官、发型、衣服、灯具、窗框、灯光和镜头。整段约5秒，人物安静望向窗外，持续轻呼吸，中段完成一次缓慢自然眨眼，随后保持原来的注视方向；雨滴只在窗外轻微滑落。双手保持原位，不抬手、不转头。镜头固定，无推拉摇移；不要分屏、拼图、滚动、边框、文字或换景。输出真正的动画GIF文件，不以单张图片或接触表代替。动作需有连续中间阶段，不能只交几张静止姿态。

候选动作时间仅作语义引导，不保证工具会精确遵从。检查全部真实源帧后决定是否通过；不能将工具拒绝转换为静图组装后仍称原生成功。

## 历史抬手提示词（保留，非当前默认）

该示例保留原制作经验。完整历史30帧补间结果在抬手处仍有重影，未通过新一轮完整动作视觉验收；需要遮挡专项复测，不在首次恢复原链路时同时引入。

生成一个 9:16 原生 GIF，作为 5 秒情绪短片的一镜。使用参考图，完全锁定人物身份、五官、发型、衣物、灯具、窗框和静态背景，不得换景、不推拉摇移、不重构图。动作时间线：0–1s 眺望、轻呼吸；1–2s 一次自然眨眼；2–4s 右手以平滑连续轨迹缓慢抬起；4–5s 指尖轻触玻璃并安静停留。每帧都是完整画面，不得输出多图错位、滚动分屏、重复边框、滑动拼图。按当前工具实际允许的帧数，优先稳定连续的完整源帧，动作进度均匀、手指数量与身体比例不变。雨滴轻流动，其他背景几乎静止。生成后的 GIF 将独立进行逐帧解码与光流补间。

## 禁止设计
- “让画面不停动起来”这种无方向性抽象指令。
- 同一镜头内同时转头、抬手、走路、推镜、换景。
- 让每一帧随机重新绘制人物。
- 在真实图像中嵌套伪 GIF 预览边框、交错排版或滚动图片。

## 工具适配与失败回退（v1.1）

提示词描述画面与动作，不是工具参数许可。先查看本次GIF工具的frame_count范围及能否取得GIF本体。当前接口2–16帧时，先尝试12–16张完整画面，或使用已经合格的历史30帧源；不得谎称工具输出30/120原生帧。若只能做稀疏帧，就降低动作幅度，以慢眨眼／轻呼吸等微动为主；手指接触、快速运动必须单独验收。

若出现整图滚动、人物改变、拼图边缘或片段衔接断裂，重做源；缩放、稳定算法或光流都不能把错误语义变正确。只返工问题镜头，保留已确认首帧与角色参考。

若有参考图编辑请求，先真实查看参考，再用当前原生工具的参考图接口锁定，不擅自改造人物或道具。多段生产只有在上一段末姿态被下一段实际继承且完整检查通过时才可组合；不得默认分段必然连续。

本轮实际调用验证：接口虽有GIF参数，但请求返回HTTP400 `GIF output is not enabled for this request`。在该会话状态下停止重新生成承诺，使用已有真实源文件；不得转去收费API或把静态图合成冒称GPT原生GIF。

补测无参考图16帧请求仍为同样400，不能仅归因于参考图。原生生成追溯、官方资料冲突和后续验收条件见 [生成复核](NATIVE_GIF_RESEARCH.md)。
