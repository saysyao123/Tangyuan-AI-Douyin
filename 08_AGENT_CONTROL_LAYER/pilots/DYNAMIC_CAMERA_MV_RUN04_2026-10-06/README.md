# Run04 · 《若爱有尽头》人物动态与运镜完整 MV

用户认可 Run03 的人物动作作为动态补充，并授权将其与运镜结合完成整片。此目录在电影插画 A、原完整音源和八句字幕锚点上制作完整 21.36 秒版本。先前 Run02、Run03 保留。

本轮新增一组伸手图集，采用 GPT 图片生成；沿用此前攥围巾图集。角色是有限帧插画动作，环境和镜头按时间确定性合成；没有调用视频生成模型，没有制造全身滑移来冒充走路。输出 30fps 不等于角色拥有 30fps 自然逐帧表演。

## 动作素材的实际使用

`gesture_atlas.png` 是此前用户认可的八姿态图集。本轮 `reach_atlas.png` 生成六格，实际用五个姿态：低位、抬起、伸出、尝试收指、退回。第四格手指超出单元边界，未采用；相邻格左边缘的溢出由固定 48px 透明边缘裁切避开。裁切是动画渲染时消费图集，原始 PNG 字节保持。

角色的头、肩与身体构图保持固定，动作由姿态交接实现，左侧发梢/围巾有轻微二级风动。近景图集有限分辨率与有限姿态的交接仍是审美边界，不以动感分数掩盖。

## 复现

取本目录代码，将素材包中的 `engine/` 合并到同名路径，把 `audio/` 放在本目录。字体与许可随素材包提供。

```bash
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
python3 engine/render.py --film night --fps 30 --crf 18 --audio audio/若爱有尽头_完整素材提取_21.4s.mp3 --out full_mv.mp4
python3 verify_export.py full_mv.mp4 audio/若爱有尽头_完整素材提取_21.4s.mp3 --out export_verification.json
python3 qa.py --project engine --film night --fps 15 --sub-band 0 --out qa
```

`verification/` 为实际技术检查；`INDEPENDENT_REVIEW.md` 为只看成片的独立审片。字幕区域自动几何检查本轮关闭，字幕构图以实际成片目视复核为证；原用户确认的音源/时间轴沿用，不把包络相关性冒充主观音画验收。

正式 S0/S1 和上游阶段批准状态没有由此实验目录擅自升级。该片交付用于用户查看整片效果，下一阶段审美批准以用户反馈为准。
