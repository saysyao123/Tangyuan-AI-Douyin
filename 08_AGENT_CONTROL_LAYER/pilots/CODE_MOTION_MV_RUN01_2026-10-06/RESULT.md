## 精度与边界

- 八句歌词沿用原字幕视觉时间轴，容差约±0.25秒，不是词级单帧对齐。
- 本轮复用用户已确认的原音频，没有重新进行音频主观听验。包络检验只说明合成后的音轨被完整保持，不能证明唱词语义。
- 几何剪影和简化步行动作能形成画面叙事，不代表能替代真人复杂表演。
- 这轮证明“已确认音频 → 已有时间轴 → 代码动画 → 完整视频”可运行；没有证明选歌、获取、分析到制作的全自动流程已跑通。
- 正式 Fresh Project 的 S0/S1 状态与人工否决全部保留，不修改旧 run、冻结合同或全局 tracker。
