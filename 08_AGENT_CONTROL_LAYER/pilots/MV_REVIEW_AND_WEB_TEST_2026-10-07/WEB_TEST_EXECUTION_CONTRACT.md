# 普通 ChatGPT 网页执行契约

目标环境由用户选择为普通ChatGPT网页，而不是独立网页工作台。官方查阅：2026-10-07，https://learn.chatgpt.com/docs/web 与 https://learn.chatgpt.com/docs/image-generation 。官方资料说明Chat／Work任务侧重点、网页参考图生成及设置影响；没有证明新会话拥有此处shell、Playwright、ffmpeg等工具。因此执行能力必须先实测，复制技能文字不授予工具。

## 上手

下载本轮用户指南与素材ZIP，解压。在新会话上传指南，或复制其中“可直接复制”指令；再附bridge.png、gesture_atlas.png、tail_audio.wav、字体。若不能读取ZIP，分别上传解压后的文件。baseline_tail.mp4只作旧版参考，不作为新的固定镜头输出。指南中的素材参数足够完成小段测试，无需第一轮连接GitHub。

## 能力门

先读取真实PNG alpha、WAV时长及字体；实际运行并导出2秒带声音小样。只有实际可下载、可播放文件才算视频执行通过。无代码执行则不得假称渲染；无MP4编码器则不得用改后缀代替转码。

路线A：可直接导出 → 制作5.110907s固定／单次微推两个候选，报告实际尺寸、帧数、音频、格式及限制。

路线B：仅能生成可下载代码 → 单文件Canvas HTML，不依赖CDN；用户打开文件，选两张PNG、WAV、字体，A/B预览及精确时间拖动。录制前检测Canvas流、Web Audio和MediaRecorder支持，按实际编码格式命名。录制失败保留预览，标记具体失败。浏览器实时录制不等于确定性逐帧渲染；如果帧率／音画同步未测，不承诺恒定30fps。

路线C：不能生成文件 → 完整HTML源码与UTF-8保存步骤，明确代码交付。若要助手完成视频渲染，使用具备执行环境的Work；普通聊天端不做未经验证的能力承诺。

## 运行与艺术分别验收

技术：asset哈希、透明通道、cell规格、字体、音频5.110907s、两版字幕同一时刻、字幕不随相机放大、实际导出参数、无黑帧。测试目标30fps，受帧量化的时长差必须报告，不截断歌声以追求整数帧。

艺术：角色与扶围巾是否仍获认可；固定镜头事件是否读得懂；B微推是否带来价值；无第二次推拉、无无因果景别切换。技术通过不能替代用户判断。

控制变量：A/B只改相机。原风动全局时间为16.25+t。图集透明留白保持；不以预览底色判断需抠图。首轮不新增生图、不重新裁掉透明留白、不做新骨骼、不改接触时刻。若调整动作，就另开实验。

若生成新视频作为正式交付，仍需执行原技能要求的技术检查与独立审片；当前轮只准备报告与素材，不将未渲染计划登记为成片通过。
