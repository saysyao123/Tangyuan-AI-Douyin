## 为什么不重复读两套生成详情

581 个案例同时有中文与英文详情，共 1,162 个生成文件。逐项研究以 `data/cases.json` 为内容依据，生成器检查保证对应输出未偏离它；因此覆盖的是每个记录及其派生文件，而不是把重复页当作新增 1,162 个技术教程。双语是否忠实于作者完整原文仍需逐条来源与翻译复查，本轮不声称完成了此项。

## 手写模块逐项分析

| 模块 | 读到的机制 | 学习经验／边界 |
|---|---|---|
| 根 README / README.en | 导览、代表作品、分类、统计与资源索引 | 概览优先；代表作品选择不等于独立质量评审 |
| AGENTS.md | 数据编辑、核验、生成与公开边界 | 是上游维护规范；只阅读，不将其安装为汤圆生产规则 |
| CONTRIBUTING.md | 提交内容与验证入口 | 必须回到来源，不填补未知素材和过程 |
| CHANGELOG.md | 功能与维护方式演进 | 理解设计变化；历史统计不是当前事实源 |
| LICENSE / THIRD_PARTY.md | 自编代码文档 MIT 与第三方权利分离 | 代码许可不覆盖视频、原曲、提示词、品牌 |
| docs/SOURCES.md | 指令、转述、未知及互动快照 | 信息来源与排序依据必须公开可解释 |
| docs/QUALITY.md | 资料、播放、筛选、完整视听独立验收 | 收录标准不等于制作质量标准 |
| docs/DISCOVERY.md | 查重、主帖、作者、媒体与资源对应 | 同名仓库不是归属证明；多附件不能漏算 |
| docs/MAINTAINING.md | 新增、更正、媒体、指标、删除恢复、评价 | 单一数据源和事务更新避免残留文件 |
| docs/DEPLOYMENT.md | 预览、白名单包、Pages、媒体失效 | Git 提交成功与网站实际更新分开 |
| docs/PUBLIC_PRIVATE.md | 数据白名单、本地研究与公共交付边界 | .gitignore 不能清除已提交历史 |
| docs/COVERAGE.md | 较早的 343 条统计 | 与当前 581 条不一致；本次使用数据重算 |
| scripts/build.mjs | schema 验证、双语生成、Markdown 围栏、显示策略 | 不能只维护前端统计；正文显示方式必须一致 |
| assets/gallery-model.mjs | 筛选、排序、完整集合导航、资源兼容去重 | 新旧资源字段按 URL 去重；null 指标不当 0 |
| assets/gallery.mjs | DOM、详情、焦点、历史、播放回退与管理入口 | 可访问性与失败路径属于真实浏览体验 |
| assets/gallery.css / index.html | 响应式卡片、详情、控件、缓存版本与 no-referrer | 外部媒体依赖会影响入口；CSS 非逐行视觉测试 |
| scripts/curation.mjs | 乐观版本、日志、备份、回滚、启动恢复 | 多文件修改要保证失败后仍可继续工作 |
| scripts/serve.mjs | loopback、Host/Origin/token、路径安全与请求限制 | 本地写接口不随静态包公开 |
| scripts/catalog-privacy.mjs | 嵌套字段白名单与 source_link 全文限制 | 隐私边界落实到数据结构，不能只写说明 |
| scripts/privacy.mjs | 编码、文本判定、敏感字段与路径检查 | 自动扫描只减少风险，不证明绝对无遗漏 |
| scripts/check-release.mjs | 工作树和暂存区、身份、链接、大小、符号链接 | 发布前检查当前内容，不自动修复历史 |
| scripts/check-target.mjs | 固定仓库与 origin 目标核验 | 防止往错误仓库发布；不是其他项目的通用推送指令 |
| scripts/package-site.mjs | 引用先检验、白名单、标记目录、静态子路径 | 成品只带必要文件；不托管 MP4 |
| scripts/metrics.mjs | 主帖 ID／作者一致、非负安全整数、null | 互动数据必须来自同一来源与同一快照 |
| scripts/check-media.mjs | 有限 Range、ftyp、200/206、类型、超时和并发 | 只看 MP4 头部，不能证明完整解码与视听质量 |
| 三个 Actions workflow | 目录校验、固定目标 Pages、每日媒体头检查 | CI 通过不等于作者作品全部可复现 |
| 两个 issue template / config | 新案例与纠错／移除入口 | 目录需要支持来源修正和撤回 |
| tests 的 15 个文件 | 数据、生成、画廊模型、媒体、隐私、资源、服务、事务、包等 | 共 81 个测试通过；详见执行收据 |
| 18 个 browse 文件 | 双语分类与资源入口 | 按生成一致性覆盖，不新增实现证据 |
| 128 个 prompts 文件 | 原文或转述纯文本输出 | 本研究读取但不重发原作者全文 |
| 581 个 cover 文件 | 记录取帧和作品视觉线索 | 单帧不能审查动作、音效或片段连贯性 |
| 其余静态图与配置 | 站点预览、品牌、忽略范围等 | 资产登记；未把品牌图当可复用作品素材 |

逐文件记录中的来源链接固定到上游提交，便于重新核对。文件级完整性由 [verify_research.py](verify_research.py) 检查；它不把哈希完整误报为每行知识都理解，也不替代视觉与声音评审。
