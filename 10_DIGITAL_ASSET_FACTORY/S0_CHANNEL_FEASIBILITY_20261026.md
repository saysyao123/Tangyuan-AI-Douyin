3. 记录真实版税、KDP 扣税、连连费率和汇率、实际到账人民币/时间，保留个人税务所需凭据；未卖出书不能证明真正收款成功。

### 苏格拉底八问（此步骤的反证）
1. 为什么先做？真实版税收款可行性是商业最短板；无此能力生产不等于盈利。
2. 为什么不直接用境内储蓄卡？KDP 当前直连 EFT 地区表未列中国大陆。
3. 为什么不是 PayPal？KDP 官方直接排除以 PayPal 作为其付款方式。
4. 有什么替代？其他参与 PSP 计划的 PingPong/Payoneer，或者真实存款银行账户；必须分别核查费用、个人账户适配与 KDP 后台限制。
5. 什么会推翻选择？KDP 要求存款银行、连连不受理个人、不可接受年费/预付款、KYC 失败或资金材料不被接纳。
6. 最薄弱假设？用户 KDP 账号实际获得 PSP 使用资格，目前未知。
7. 如何验收？本人后台税务 Complete、银行验证通过、官方 PSP 完成 KYC、真实到账记录；说明书不能替代账户状态。
8. 后期维护风险？税务 W-8 到期、KYC 更新、支付冻结、汇率费用与版权拒稿，必须管理而非宣称零售后。

### 成本与状态
当前本研究没有触发新增付费动作。连连页面 KDP 1% 提现费率属于从实际版税中扣款的交易成本，不能声称净收益不受影响。用户明确 0 新增现金投入，不接受新的月费、年费、预付充值、AI API 费；若实付费用无法避免，先停止而非代付。
真实状态：REGISTRATION_NOT_PERFORMED / ACCOUNT_ELIGIBILITY_UNKNOWN / TAX_NOT_DONE / KDP_PSP_NOT_VERIFIED / LIANLIAN_ACCOUNT_NOT_OPENED / NO_BOOK_OR_ROYALTY / ZERO_NEW_PAID_PURCHASES。
下一 Gate：用户先登录本人 KDP 检查是否存在账号与 PSP 限制，并就连连 KDP 中国大陆个人开户及全部固定费用获得官方答复；只有两者通过才进入实际绑卡与正式出版。
