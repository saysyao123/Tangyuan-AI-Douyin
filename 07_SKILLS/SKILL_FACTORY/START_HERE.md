# Skill Factory | 长期调用入口

用户调用“技能工厂”或“Skill Factory”时，先读取同目录 `STABLE.json`，按其指向加载实际 `SKILL.md`、锁定标准及必要的 references/scripts；不要用历史聊天摘要替代源码。进入相应 BUILD / SCOUT / AUDIT / EVOLVE 模式，确认当前环境能力并执行。没有访问、运行或独立测试权限时明确说明。

当前基线 V1.0.1：E1 本地控制器自测，不代表独立 Agent、跨宿主或 SkillPay 商业验收。版本目录保留原始文件，升级应新增版本目录、保存测试与回归证据，获授权后才更新 STABLE.json。默认不新增未经授权的费用，不擅自发布商品或外发客户数据。

此目录位于公开仓库，禁止提交密钥、客户资料、封存测试答案和其他非公开数据。GitHub 入口不是 ChatGPT 原生全局技能安装；跨对话调用需实际访问仓库。
