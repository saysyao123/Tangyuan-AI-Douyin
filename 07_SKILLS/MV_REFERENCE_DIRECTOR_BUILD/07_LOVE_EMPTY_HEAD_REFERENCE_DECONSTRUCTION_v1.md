1. 暗部人物近景 / 情绪钩子；

## 3. Segment A｜BGM 0.000–8.700s

### Lyric task

`爱 爱 → 爱总是 → 好了疤 → 忘了痛 → 让人脑袋空空 → 直到心破了洞 → 见了红 → 换来步履匆匆`

### Reference visual progression

- 0–约1.57s：人物近景 / 暗部轮廓，先建立情绪；
- 约1.57–3.40s：人物被放进雪山/荒野空间；
- 3.40–4.93s：大景 + 小人物，对应“脑袋空空”；
- 4.93–6.63s：人物中近景，情绪身体动作更明显；
- 6.63–7.33s：极远景小人物，短促情绪标点；
- 7.33–8.70s：背身 / 前行意图，完成“步履匆匆”。

### Transferable camera grammar

`情绪近景 → 中远景孤立 → 大景压人物 → 回人物情绪 → 极远景 → 背身/前行结束`

不要求动画版复制六个地点；建议把这些变化压缩进同一世界内的机位/景别变化。

### Transferable movement grammar

原参考动作较轻，主要价值是：

`静止 → 身体情绪反应 → 视线/手势 → 开始前行`

动画版应增强“可读动作”，但不改情绪方向。尤其 `7.333–8.700s` 必须形成真实步法或明确前行动机，不能滑行。

### Energy curve

- `0.000–3.400`：低能量、内收；
- `3.400–4.933`：第一核心句，空间打开；
- `4.933–6.633`：情绪强度上升；
- `6.633–7.333`：短促重击；
- `7.333–8.700`：动作化释放，形成切点。

### Cut-friendly ending requirement

A 的核心内容必须在 `BGM 8.700s` 对应位置完成一个动作标点：脚落地 / 转身完成 / 抬眼完成 / 构图稳定。

不设计“向 B 平滑接动作”。

## 4. Segment B｜BGM 8.700–15.370998s

### Lyric task

`从开始情有独钟 → 到最后泪眼汹涌 → 承诺全被风吹得 → 无影无踪`

### Reference visual progression

- 8.70–10.53s：雪山前人物 / 行走感，新语义段重新起势；
- 10.53–12.33s：蓝调夜色 / 极远空间，情绪放大；
- 12.33–13.77s：人物变小、环境更大，开始释放；
- 13.77–15.37s：草原/道路极开阔空间，人物趋向消失，完成 Ending。

### Transferable camera grammar

`新的中远/全景起势 → 极远景拉开 → 环境主导 → 最终开放式远景`

B 不应从 A 的最后一帧做无缝延续；应在硬切后主动换至少一个镜头维度：景别 / 角度 / 朝向 / 光线层次。

### Transferable movement grammar

`重新起步/回望 → 情绪停顿 → 环境运动接管 → 人物动作收小 → 余韵结束`

结尾不要用大动作抢掉“无影无踪”的空间感。

### Energy curve

- `8.700–10.533`：新段起势 / 回望；
- `10.533–12.333`：第二段峰值；
- `12.333–13.767`：情绪释放；
- `13.767–15.371`：消散 / Ending residue。

## 5. Hard-cut design at 8.700s

### What must remain continuous

- same original animated character identity anchor;
- same overall world / palette logic;
- emotional causality.

### What is allowed to jump

- camera distance;
- camera angle;
- character facing direction;
- environment layer / time-of-day intensity;
- character pose, provided it is independently stable.

### Recommended editorial logic

A ends on completed forward-action punctuation at `步履匆匆`.

Hard cut.

B begins as a new visual sentence at `从开始情有独钟`，用新的中远景/三分之四机位或更开阔构图重新建立人物。

This is a semantic cut, not a continuity cut.
