## 1. Director correction｜NO ONE-TAKE

当前 MV 明确不采用一镜到底作为 A/B 主方案。

借鉴此前高动态“疯批打戏”测试真正有效的导演逻辑：

- action progression；
- camera progression；
- shot-scale contrast；
- foreground/background movement；
- clear visual event on lyric / beat accents；
- physical body mechanics；
- dynamic peak followed by residue。

但不复制打斗动作。将其翻译为情绪型动画 MV：

`歌词节点 → 人物动作 → 镜头变化 → 环境响应 → 下一个切点`。

镜头变化必须服务歌词/音乐，不做无意义炫技。

## 2. Unified visual world

### Character

同一原创年轻女性冒险者：高辨识轮廓、利落中短发、短披肩/短斗篷、腿部动作可读；暖红/暗珊瑚作为角色识别色，深蓝灰/墨青作辅助色。

只借少年冒险动画的轮廓、姿态张力和表演感，不复制现成角色。

### World

同一高地湖岸世界，但允许在同一地理空间内切换子场景：

- 草坡/高地边缘；
- 湖岸石径；
- 远山雪线；
- 风口平台/山脊；
- 蓝调天空和远方道路。

A 从暖黄昏逐步进入冷色；B 进入更深蓝调。不是十个互不相关地点，而是一个世界的不同机位和空间层。

### Companion / motif

小型微光风灵作为情绪向导。它只承担：引导视线、制造空间动势、在 Ending 消散。不能抢主角。

# 3. Segment A｜Final BGM 0.000–8.700｜Generation 12s

Core generated window: `1.200–9.900s`。

导演目标：`爱反复发生 → 空掉 → 受伤 → 身体重新动起来 → 步履匆匆`。

## A1｜Hook close-up

**BGM** `0.000–1.567` ｜ **Gen** `1.200–2.767`

歌词：`爱 爱 / 爱总是`

- Shot: 中近景 / 略低机位 / 侧逆光。
- Character: 头微低，眼神失焦；第一次“爱”时眼神轻抬，第二次“爱”时风灵从肩后穿过前景。
- Camera: 极轻推近，随后在句尾做小幅横向偏移，为切镜制造方向。
- Environment: 发丝、短披肩、前景草叶微动。
- Purpose: 先抓脸与情绪，不急着开大景。

**CUT** at lyric boundary.

## A2｜Scar / pain spatial jump

**BGM** `1.567–3.400` ｜ **Gen** `2.767–4.600`

歌词：`好了疤 / 忘了痛`

- Hard cut to 中远景/全景，人物已处在湖岸石径边，身体方向与 A1 不同。
- Character: 她抬起手看一眼掌心或腕部，再把手收回；不是展示伤口，而是“旧痛被忘掉”的动作隐喻。
- Camera: 从前侧低机位快速横移到较开构图；前景草穗/石柱扫过镜头形成自然 wipe 感，但仍是明确切镜。
- Environment: 湖面反光、云影移动、风灵短促掠过。

**CUT** on `忘了痛` end.

## A3｜“脑袋空空” visual expansion

**BGM** `3.400–4.933` ｜ **Gen** `4.600–6.133`

歌词：`让人脑袋空空`

- Hard cut to 极远景 / 高位或广角，人物突然缩小。
- Visual event: 天空和湖面占据大部分画面，空间一下“空”出来；风灵从人物身边被风卷向远处。
- Character: 人物短暂停住、抬头，身体微失衡但脚底真实稳住。
- Camera: 快速拉开/升高后减速，不持续漂移。
- Purpose: 用景别变化直接把“空空”视觉化。

**CUT** on next lyric onset.

## A4｜“心破了洞” emotional impact

**BGM** `4.933–6.633` ｜ **Gen** `6.133–7.833`

歌词：`直到心破了洞`

- Hard cut back to 中近景/三分之四侧面。
- Character: 风突然增强，她先吸气，肩胸明显起伏，一只手压住胸口；身体前倾半步再稳住。
- Camera: 短促 push-in + 小幅绕侧，不超过约 30–45°。
- Environment: 头发和披肩同时受风，微光风灵绕过胸前再被甩向侧后方。
- Dynamic peak: 人物、镜头、环境三层同时增强，但动作仍克制。

**CUT** on `见了红`.

## A5｜“见了红 → 步履匆匆” kinetic finish

**BGM** `6.633–8.700` ｜ **Gen** `7.833–9.900`

歌词：`见了红 / 换来步履匆匆`

- `见了红`：用夕阳/红色光斑/红色花瓣或风灵短暂染红作为视觉标点，不出现血腥伤口。
- Hard cut to 低位侧跟 / 脚步可见的中全景。
- Character: 从静止真正迈出 2–3 个清楚步伐：抬脚→落脚→蹬地→重心转移→加速；披肩与发丝落后于身体形成惯性。
- Camera: 低位横向 tracking，随后略超前，让人物进入画面中心；最后一步在 Gen ~9.900 明确落地或抬眼完成。
- Environment: 草浪、碎光、风灵同向运动，强化速度层次。

**A FINAL PUNCTUATION**：完成态，供 BGM 8.700 硬切。不要卡在半步。

### A post-handle `9.900–12.000`

保持 A5 的动作余势/减速/完整构图；不再引入必须使用的新剧情。剪辑可自由取尾。

# 4. Segment B｜Final BGM 8.700–15.371｜Generation 10s

Core generated window: `1.500–8.171s`。

导演目标：`曾经情有独钟 → 情绪决堤 → 承诺被风带走 → 空间吞没人`。

## B0｜Pre-handle establishing

**Gen** `0.000–1.500`

K0-B 只锚定这一新视觉句：蓝调山脊/湖岸，更开阔的新机位。允许之后在 Gen 1.500 直接切镜进入正式歌词。

## B1｜“从开始情有独钟” restart

**BGM** `8.700–10.533` ｜ **Gen** `1.500–3.333`

- Hard cut into新的中景/三分之四正侧面，和 A5 的低位侧跟形成明显差异。
- Character: 她停下回望，手从胸口慢慢松开；风灵从远处回到视线前方。
- Camera: 快速而克制地绕到人物侧前方，随后稳住。
- Visual motif: 背后远山仍有暖色余光，像“开始”的残留。

**CUT** at `到最后`.

## B2｜“泪眼汹涌” emotional peak

**BGM** `10.533–12.333` ｜ **Gen** `3.333–5.133`

- Hard cut to近景/特写，眼睛是核心，但不做夸张哭喊。
- Character: 她快速吸气、眨眼，眼眶湿润；一阵风使她不得不侧脸，手抬起又没有真正擦泪。
- Camera: 短促 push-in 后侧移，前景风灵/光点擦过镜头。
- Environment: 背景景深明显变化，风声视觉化为发丝和衣料高速掠动。
- Peak: 全片人物情绪最近的一刻。

**CUT** on `承诺`.

## B3｜“承诺全被风吹得” environment takeover

**BGM** `12.333–13.767` ｜ **Gen** `5.133–6.567`

- Hard cut to较开侧后景。
- Visual event: 风灵带着若干微光纸片/花瓣/光尘被强风卷过人物，向湖面/山谷飞去；它们代表承诺，不使用可读文字。
- Character: 她伸手想抓，手伸到一半停住，然后主动放下。
- Camera: 快速横移或小幅 crane-out，环境开始比人物更重要。

**CUT** into Ending.

## B4｜“无影无踪” wide ending

**BGM** `13.767–15.371` ｜ **Gen** `6.567–8.171`

- Hard cut to极远景/高位开阔镜头。
- Character: 人物变小，停在山脊/湖岸边，不再追；只有衣摆、发丝和呼吸余韵。
- Wind spirit: 飞远、裂成几点微光并消失在天空/远山方向。
- Camera: 明确 pull-back / rise then decelerate，最后趋稳。
- Ending: 不追求悲剧终结，而是“风把东西带走后，世界仍然明亮”。

### B post-handle `8.171–10.000`

延续极远景、光点消失、草浪/云层余动，让剪辑自由选择最终 Ending 帧。

# 5. Shot-density rule

当前最终成片 15.37s 的有效视觉密度约：

- A: 5 principal shots / 8.7s
- B: 4 principal shots / 6.67s
- Total: 9 principal shots / 15.37s

这是当前歌词/Beat 驱动的结果，不是固定模板。

如果生成端无法稳定完成某个场景切换，不要求把所有镜头硬塞在一条视频里；允许新增 5–15s coverage clip，并在最终剪辑中替换对应 shot。

# 6. K0 implications

- K0-A = A1 的 pre-handle / first-shot anchor，只负责第一个镜头进入状态。
- K0-B = B0 的 pre-handle first-shot anchor；BGM 8.700 对应 Gen 1.500 后允许直接切到 B1。
- K0 不再被定义为“整条 10–12s 的连续镜头起点”。
- 后续 Dynamic Prompt 必须显式写 `Shot 1 / CUT / Shot 2 ...` 与时间区间。

# 7. Human Gate

本版先确认导演结构，再生成 K0。

需要确认的不是每个小动作，而是：

1. 接受 A/B 内部多镜头而非一镜到底；
2. 接受约 9 个主镜头覆盖最终 15.37s；
3. 接受歌词关键点用镜头/动作/环境共同卡点；
4. 接受 A→B 仍在 8.700s 直接硬切；
5. 接受必要时新增 coverage 视频，而不强迫单条生成承担所有镜头。

通过后 → K0-A / K0-B → multi-shot Dynamic Prompt v1。
