## KF01 → S1｜你的回应是一直沉默

**动态任务：静态张力 / 墨晕作为主事件。**

```text
使用当前上传的首帧作为第0秒唯一参考画面，严格保持首帧中的同一名东方女性、黑色半透明面纱、深墨绿色长衣、旧金发簪、湿木书案、旧纸、墨迹、灯光、雨夜色调和镜头构图，不改变人物身份，不改变服装，不改变场景结构，不新增任何人物或新物体。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段的导演重点不是人物表演，而是“回应没有来，字先散了”。整体克制，前2秒几乎不移动摄影机，不能做常规慢推镜头。

0.0–1.5秒：延续首帧动作。一滴刚落下的水继续向湿纸纤维中扩散，黑墨从中心向四周形成真实、细腻、不规则的晕染。女主悬在纸面上方的手指保持迟疑，仅有极轻的手部呼吸感，不能突然落下。纸页右上角被穿堂风轻轻抬高一点。

1.5–3.2秒：摄影机做非常轻微的横向贴桌滑动，不前推，从墨迹侧面移动几厘米，产生湿纸、手指与远处眼睛之间的景深层次。焦点先落在正在扩散的墨边，再缓慢转移到悬停的指尖。女主的手指在接近纸面后又极轻地收回约一厘米，像最终放弃写下回应。

3.2–5.0秒：纸页被第二股轻风掀起更多，但不能飞走；掀起的纸角短暂扫过画面下部，墨水仍在慢慢扩散。女主眼睛保持压低，没有哭泣、没有抬头。最后0.5秒保持一个稳定余韵，方便后期切到下一段。

主视觉事件：湿纸上的墨迹持续晕开。
次级物理余韵：悬停手指轻轻收回 + 纸角被风抬起。
摄影机：静态张力开始，随后极轻横向滑动；禁止全程慢推。
动态强度：低到中低，动作少但必须真实。

严禁：新增第二人物、可读文字、字幕、logo、水印、纸张突然飞散、人物大幅转头、夸张哭泣、面纱消失、服装变化、场景变换、快速推拉变焦、魔法墨水、黑烟特效。
声音：不要AI对白、歌声、旁白或BGM；如模型必须生成声音，只允许极轻雨声、纸张摩擦声、风声。
```

## KF02 → S5｜你有没有真的爱过我

**动态任务：人物微表演 / 情绪中心。**

```text
使用当前上传的首帧作为第0秒唯一参考画面，严格锁定同一名东方女性的眼睛、脸型、黑色半透明面纱、黑发、旧金发簪、深墨绿色服装、手中湿纸、雨夜背景与光线。绝对不能换脸、换人、露出嘴唇或移除面纱，不新增第二人物。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段是全片“你有没有真的爱过我”的情绪中心。不要设计大动作，不要切换新场景，不要炫技；核心是压抑很久以后，她终于把视线抬起来问出去。

0.0–1.6秒：镜头几乎不动。女主保持首帧姿态，眼睛仍略微向下；呼吸带来极细微的肩颈起伏。一缕湿发和面纱下缘被很轻的风带动。她捏住湿纸的手指开始稍微收紧，纸边轻微变形。

1.6–3.4秒：女主的视线缓慢抬起，不是突然抬头，先抬眼、后有极小幅度的头部变化。摄影机只做非常克制的5%–8%稳定推进，目的是让双眼逐渐成为画面中心，而不是制造明显运镜感。眼睛湿润但不流泪，不哭喊。

3.4–4.5秒：她的目光停在镜头旁边一个空位置，像真正向一个缺席的人发问。手中的湿纸再被捏紧一点，但不撕裂。背景雨光轻微移动，人物保持稳定。

4.5–5.0秒：完全停住视线与身体，只保留发丝、面纱、雨光的微余韵，留出剪辑停顿。

主视觉事件：女主从垂眼到真正抬眼发问。
次级物理余韵：捏纸力度增加 + 面纱与湿发轻动。
摄影机：极克制近景微推进，仅这一段允许明显的情绪型慢推，但幅度必须小。
动态强度：中等，情绪高、物理动作低。

严禁：新增人物、镜头突然绕人物旋转、流泪大哭、张嘴说话、面纱掉落、换脸、换装、抖动镜头、突然强光、纸张撕裂、夸张风吹。
声音：不要AI对白、歌声、旁白或BGM；只允许极轻雨声与布料风声。
```

## KF03 → S6｜我是你诗的哪个段落

**动态任务：空间穿行 / 纸页层叠成为主事件。**

```text
使用当前上传的首帧作为第0秒唯一参考画面。严格保持首帧中同一名东方女性、黑色半透明面纱、深墨绿色长衣、旧金发簪，以及层层悬挂的巨大湿纸、旧宅长厅、湿木地面、灯光和冷青灰色调。不能新增人物，不能把纸变成文字墙，不能出现可读汉字或英文。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段对应“我是你诗的哪个段落”，重点是让人物真正进入纸页形成的空间，而不是普通站立加慢推。动作必须有明确的空间前进与纸层视差。

0.0–1.3秒：延续首帧。前方一张湿纸下缘继续被风抬起，形成窄窄的通道。女主刚抬起的脚向前落下一步，手仍未完全触碰纸面。摄影机保持稍后方、略偏侧的位置，不急着前推。

1.3–3.2秒：摄影机与女主同步做短距离横向跟随 + 轻微向前穿行，通过第一层纸页时形成明显的前景遮挡和纵深视差。纸页依次被风带动，前层先动、后层稍晚动，形成连续波动，但纸不能疯狂翻飞。女主只走一到两步，保持克制。

3.2–4.4秒：摄影机从一张纸页边缘后方重新显露女主，让她被两三层半透明纸页包围。前后纸面的抽象墨痕出现轻微重叠，像她逐渐进入“段落”结构，但不能出现任何可读文字或魔法发光字。

4.4–5.0秒：女主停在纸层深处，最前方一张纸仍缓慢摆动，短暂遮住她半边身体，再露出，形成余韵。

主视觉事件：女主穿过层层湿纸构成的空间。
次级物理余韵：纸页按前后层级依次受风波动 + 湿墨边缘轻微继续晕开。
摄影机：侧后方跟随穿行 + 前景遮挡视差；禁止简单正面慢推。
动态强度：中高，空间变化强于人物动作。

严禁：新增第二人物、文字飞舞、纸张变成鸟或碎片、魔法粒子、人物瞬移、快速奔跑、场景突然扩张成仙境、换脸、换衣、面纱消失。
声音：不要AI对白、歌声、旁白或BGM；只允许纸页摩擦、轻风、远雨声。
```

## KF04 → S2｜只剩下落寞

**动态任务：横向揭示 / 用空间表现孤独。**

```text
使用当前上传的首帧作为第0秒唯一参考画面，严格保持同一名东方女性的背影、黑发低束、旧金发簪、深墨绿色长衣、黑色面纱、长廊、雨夜庭院、湿地反射、灯笼位置和冷青灰光线。不新增任何人物或动物，不改变建筑结构。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段对应“只剩下落寞”。重点不是走路，而是让摄影机逐渐揭示她周围巨大的空空间。禁止常规正后方慢推。

0.0–1.2秒：延续首帧，女主刚停下脚步，身体保持背向或侧背。穿堂风把衣摆和外层薄纱向一侧拉起一点，地面积水产生第一圈细波。她不回头。

1.2–3.5秒：摄影机从一根近景廊柱后开始缓慢横向滑动，像从遮挡物后“看见”她，同时逐渐揭示更大的空庭院与无人门口。人物在画面里的比例保持较小，不要推近。随着摄影机横移，廊柱、灯笼、湿地形成明显前后视差。

3.5–4.5秒：摄影机继续横移少量距离后停止。女主只做一个极轻微的重心变化，像想继续走又停住。远处薄雾缓慢进入廊内，雨水反射轻轻晃动。

4.5–5.0秒：保持大空间静止，衣摆和雾继续有轻微余韵，让孤独感落下来。

主视觉事件：摄影机横向揭示巨大空庭院，人物始终很小。
次级物理余韵：衣摆受风 + 地面涟漪 + 薄雾漂入。
摄影机：横向滑轨式揭示，绝不向人物慢推。
动态强度：低到中低，空间信息强，人物动作弱。

严禁：新增路人、远处人物、女主突然转身、奔跑、回头看镜头、灯笼大量闪烁、暴雨突然增强、建筑变化、换装、换脸、面纱消失。
声音：不要AI对白、歌声、旁白或BGM；只允许雨声、风声、很轻的衣料声。
```

## KF05 → S3｜我有什么错

**动态任务：倒影扰动 / 自我质问。**

```text
使用当前上传的首帧作为第0秒唯一参考画面。严格保持同一名东方女性、黑色半透明面纱、黑发、旧金发簪、深墨绿色长衣、雨夜庭院、水面位置、真实人物与水中倒影的身份一致。水中倒影必须永远是她自己的同步镜像，绝对不能生成第二张陌生人脸或第二个人。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段对应“我有什么错”，核心视觉不是人物哭，而是她主动触碰水面，让自己的倒影被打散。

0.0–1.1秒：延续首帧，女主食指继续缓慢下降，已有的细小雨滴涟漪还在扩散。摄影机保持稳定，水中倒影清楚可辨，但边缘已有轻微扭曲。

1.1–2.2秒：指尖第一次轻触水面，只触一下，不用力戳。接触点产生一圈新的清晰涟漪，迅速向倒影中的双眼和面纱扩散。真实人物保持低头，动作克制。

2.2–3.7秒：摄影机缓慢下降到更接近水面高度，并略微向水面倾斜，让倒影从画面下半部逐渐成为主体。涟漪经过倒影的眼睛，使“她看自己”的画面短暂被分裂、拉伸、错位，但仍能确认是同一人。

3.7–4.6秒：女主手指从水面轻轻离开，水珠从指尖落下一滴，再形成很小的第二层波纹。她的真实眼睛仍看着水面，不抬头。

4.6–5.0秒：摄影机停在近水面角度，倒影仍在轻微恢复，但没有完全平静，留下一种未解决的自问。

主视觉事件：指尖触水，涟漪打散自己的倒影。
次级物理余韵：指尖离水后的水滴 + 倒影缓慢恢复。
摄影机：从半近景缓慢下降到近水面角度；不是推近人物。
动态强度：中等，主要变化发生在水面。

严禁：倒影变成第二人物、倒影自己独立行动、女主把手伸进水里、出现怪异面部、换脸、面纱消失、突然大哭、镜头剧烈晃动、水面爆炸或魔法波纹。
声音：不要AI对白、歌声、旁白或BGM；只允许雨滴、水面轻响、轻风。
```

## KF06 → S4｜短暂柔情似流星划落

**动态任务：事件驱动重构图 / 全片第一次明显动态高点。**

```text
使用当前上传的首帧作为第0秒唯一参考画面，严格保持同一名东方女性、深墨绿色长衣、黑色面纱、旧金发簪、湿石平台、远山/古建筑轮廓、雨夜云层、地面旧纸和唯一一颗流星。不能新增第二颗流星、不能新增人物、不能把场景变成玄幻世界。

生成一段固定5秒、9:16竖版、电影级写实动态视频。

这段对应“短暂柔情似流星划落”，是前半段第一个明显视觉高潮。动态核心是流星真实划过 + 风被瞬间带起 + 地面反光变化。摄影机必须被“事件”带动，而不是普通推镜。

0.0–1.2秒：延续首帧。唯一一颗流星继续沿当前方向快速拉长银白光轨，云层被它短暂照亮一点。女主开始抬眼，但身体仍基本不动。地面纸页的一角被突然增强的风抬得更高。

1.2–2.7秒：摄影机做一次稳定、流畅的向上倾斜跟随，从女主与湿石平台快速但不突兀地抬向流星轨迹，短暂把流星放到画面主要位置。衣摆、面纱、发丝因风明显摆动，但人物不能失去重心。

2.7–3.8秒：摄影机顺势从天空重新压回到较低角度，让流星的银白光在湿石地面和浅水反射中划过，旧纸被风掀起并向前滑动或翻起一次，但不要飞出画面。女主被流星边缘光短暂勾亮。

3.8–4.6秒：流星亮度快速减弱，光轨开始消退。风势也从强转弱，纸页落下一部分，衣摆仍有惯性余摆。

4.6–5.0秒：留住湿地最后一条银色余光和衣摆回落，形成“很美，但已经过去”的结束感。

主视觉事件：单颗流星完整划过并短暂改变画面光线。
次级物理余韵：风带起纸页、衣摆、面纱，随后逐渐回落。
摄影机：事件驱动的上倾跟随 → 顺势回落到地面反射；禁止常规慢推。
动态强度：高，是全片最明显的环境事件之一。

严禁：多颗流星、陨石撞击、爆炸、闪电、魔法光、人物飞起、纸页漫天飞舞、新增人物、仙侠法术、换脸、换装、面纱消失、镜头360度旋转。
声音：不要AI对白、歌声、旁白或BGM；只允许短暂增强的风声、雨后环境声、纸张摩擦声。
```

## KF07 → S7｜落款第几页 / 第几次临摹

**动态任务：微距动作 / 痕迹叠加。**

```text
使用当前上传的首帧作为第0秒唯一参考画面，严格保持同一双手、同一东方女性背景轮廓、深墨绿色袖口、黑色面纱、旧毛笔、湿木桌面、层叠旧纸和现有抽象墨痕。绝对不能生成可读汉字、名字、签名、英文、数字或清晰印章文字；不能新增人物。

生成一段固定5秒、9:16竖版、电影级写实微距动态视频。

这段对应“落款第几页 / 第几次临摹”，核心不是书法，而是“同一痕迹被一次又一次覆盖”。保持近距离微距摄影，不需要人物脸部表演。

0.0–1.4秒：延续首帧。毛笔完成当前抽象笔划最后一小段，速度很慢，笔尖压在湿纸纤维上，新墨从笔迹边缘真实渗开。另一只手继续压住多层纸。
```
