# WEB R2｜W06 Camera Prompt Experiment v1

> 状态：`EXPERIMENTAL / NOT PROMOTED`。本文件只用于当前《如果你也刚好抬头看树》9条 Seedance 2 mini 5s 图生视频测试。生成结果未回传前，不把本轮新运镜写入 `04_HARNESS/rules/ai_video.md` 的硬规则。

## 1. Research Inputs

本轮先研究再写提示词，主要吸收以下开源项目：

1. `songguoxs/seedance-prompt-skill`
   - Seedance 2.0 多模态引用、参考视频运镜复刻、4–8秒短片策略、禁止项、MV/卡点思路。
   - 关键取舍：5秒片段不使用精确时间戳；只保留1个主摄影机语法 + 1个主视觉事件。
2. `Emily2040/seedance-2.0` / `seedance-camera`
   - Camera Contract：景别 / 角度 / 运动 / 速度 / 主体关系 / 起点 / 终点 / fragile anchors。
   - 一条短片只用一个清晰主运镜；复杂运镜优先用参考视频，而不是堆叠文字指令。
3. `yinxiaowai/awesome-ai-video-camera-movement-prompts`
   - 基础与进阶运镜案例库；强调起点、终点、速度、情绪；15秒内只用1–2种运镜。
4. `fal-ai-community/skills` / cinematography
   - 具体镜头语言优先于“电影感、史诗感”等空泛形容；镜头、光线、构图、动作必须物理一致。
5. `maciejdzierzek/seedance-prompt-generator`
   - Seedance 2.0 模板中明确：one camera movement per shot；精确 shot duration 不稳定；稳定性/禁止项属于配置而非装饰。
6. `SleenT/CinePrompt`、跨模型导演技能资料
   - 补充 Static / Dolly / Truck / Steadicam / Crane / Jib / Orbit / Whip Pan / Rack Focus / POV / Worm’s Eye / Bird’s Eye 等词汇。

## 2. Camera Vocabulary Pool

### A｜当前 Seedance 5s 优先测试
- Locked-off / 固定机位
- Dolly push-in / push-out
- Truck left / right / 轨道横移
- Pan left / right / 水平摇镜
- Tilt up / down / 垂直摇镜
- Pedestal up / down / 摄影机整体升降
- Tracking / lead / follow / 跟拍
- Arc / half-orbit / 小角度弧形绕摄
- Crane / Jib / 升降或扫臂揭示
- Rack focus / 焦点转移
- Macro glide / 微距滑移

### B｜可测试但风险更高
- Whip pan / 快速甩镜
- Dolly zoom / 希区柯克变焦
- Crash zoom / 突然光学变焦
- Subtle handheld / 轻手持
- POV / 主观视角
- Drone / aerial tracking
- Optical zoom in/out
- Foreground occlusion reveal

### C｜当前抒情 MV 暂不使用
- 强烈 FPV 追逐
- Full 360 orbit
- Camera roll
- Strong shake
- Bullet time
- 高速 fly-through

原因：这些并非“不能生成”，而是与当前歌曲的松弛、诗意、巨尺度克制美感冲突，并增加人物/面纱/场景结构失稳概率。

## 3. Test Hypothesis

`丰富 ≠ 单条提示词堆更多运镜`。

本轮假设：
- 每条5秒内部：`1个主摄影机语法 + 1个主事件 + 1个物理余韵 + 明确终点`；
- 9条之间：主动使用不同的摄影机语法，形成 MV 的多视角覆盖；
- 不使用统一“慢推”模板；
- 不把9条做成空间连续的一镜到底；统一的是人物、服装、面纱、巨树/灰白建筑、光色与情绪，不统一镜头路径。

## 5. Shared Hard Constraints

每条人物图生视频提示词第一行必须原样使用：

`*** 人物为 AI 生成动画人物，无真人出现。当前上传图片是 AI 生成的虚构影视动画角色设定图，不是真人照片，不含真实人物，不是真实人脸参考素材，不按真人或真实肖像处理。`

全组共同约束：
- 5秒，9:16；当前上传图为第0秒锚点；
- 同一虚构东方女性；灰白/沙白层叠长衣；同色轻薄功能型面纱始终完整遮住鼻口和下半脸；
- 不新增人物、路人、局部人体或第二张脸；
- 某段首帧没有鸟则不得临时新增鸟；有鸟的段落只保留首帧已有的一只；
- 不生成文字、字幕、Logo、水印；
- 一条只执行一个主摄影机运动，不自行加入慢推、呼吸Zoom、随机横漂或反复摇摆；
- 轻纱保持连续完整拓扑，不破洞、不复制、不变成多条独立布带；
- 人物动作自然克制，真实重力与布料惯性；
- `SOURCE_AUDIO = REMOVE`：不依赖生成音轨，最终BGM后期加入。

## 7. Evaluation Plan

本轮不是验证“提示词写得是否高级”，而是验证以下可观察结果：

1. Camera compliance：主运镜是否真的执行，是否私自加入慢推/漂移；
2. First-frame preservation：首帧构图美感是否被破坏；
3. Identity / veil continuity：人物、面纱、衣服是否稳定；
4. Motion readability：主动作是否一眼看懂；
5. Physical quality：布料、头发、树叶、鸟是否符合惯性与拓扑；
6. Endpoint quality：结束帧是否可剪，不悬在坏动作中；
7. Whole-set diversity：9条剪在一起是否仍像同一种运镜模板。

建议先验证代表三种难度的 `S1（Locked） / S3（Rack Focus） / S7（Pedestal Up主峰值）`。如果三类均稳定，再批量跑剩余6条；如果某一类失败，只修该类，不把失败经验直接晋升为硬规则。
