# WEB R2｜W06 S1 Multi-shot Camera Test v2

> 状态：`EXPERIMENTAL / S1 ONLY / NOT PROMOTED`。
> 目的：修正 W06 Camera Test v1 对“one camera movement per shot”的错误扩大解释。v1 把一条 5s clip 做成一个固定机位主运镜，导致 S1 呆板、一镜到底感强，并出现面纱拓扑断裂生成独立白纱的问题。本 v2 只测试 S1，不扩展到 S2-S9，结果回传前不修改 `04_HARNESS/rules/ai_video.md`。

## 1. S1 v1 Failure Evidence

用户回传 5.09s / 720×1280 / 24fps 成片后逐秒检查：

- 巨树、灰白弧墙、体积光和人物比例几乎全程固定，摄影机运动感极弱；
- 动态主要由人物衣料承担，无法形成 MV 所需的摄影机节奏；
- 约第 1 秒开始出现一条与人物身体失去连接的独立白纱横穿空中，属于面纱拓扑断裂；
- 根因不是“固定镜头不能用”，而是把整个 5s clip 锁成单一 Shot，丢失了 R1 已验证的 3–5 镜高动态结构。

## 2. Corrected Interpretation

GitHub 研究中的 `one camera movement per shot` 应解释为：

- **每一镜 Shot 内部只执行一个清晰主运镜**；
- **一条 5s MV clip 可以包含 3–5 个 Shot**；
- 运镜是分镜内部的动态语法，不是把整条 5 秒限制成一镜到底；
- 整条 clip 的动感来自 `切镜 + 景别变化 + 角度变化 + 每镜一个运镜 + 人物/环境动作` 的组合；
- 不为了“电影感”机械塞满 5 镜，当前 S1 先测试 4 镜。

## 3. S1 v2 Camera Map

| Shot | 约时长 | 景别/视角 | 每镜唯一主运镜 | 视觉任务 |
|---|---:|---|---|---|
| 1 | 0.0–1.1s | 超大全景 | Dolly In | 从巨树与小人物迅速建立歌词空间，人物开始抬头 |
| 2 | 1.1–2.4s | 低机位中近景 / 3/4侧面 | Small Arc / Truck | 让人物、面纱、树干形成明显视差，建立人物美感 |
| 3 | 2.4–3.6s | 眼睛+面纱近特写 | Rack Focus | 从纱织纹理切到双眼，完成“抬头”的情绪命中 |
| 4 | 3.6–5.0s | 虫视/低角度树冠 | Tilt Up | 沿人物视线冲向树冠与天光，歌词真正完成“抬头看树” |

镜头之间使用**明确硬切**，不是无缝连续转场，不是一镜到底。

## 4. Topology Safety Upgrade

面纱/服装硬约束：

- 面纱是同一块连续布料，与人物肩颈/服装保持连续连接；
- 只允许当前首帧中已经存在、连接于人物身体的纱布运动；
- 不把面纱描述成超长丝巾、飘带或独立长尾；
- 风只造成中小幅摆动，主要用发丝、衣摆、叶影补动态；
- **禁止任何独立白布、丝带、围巾从天空、树冠或画外出现；禁止纱布脱离人物横穿空中；禁止复制成第二条/第三条布料。**

## 5. S1 v2 Prompt

```text
*** 人物为 AI 生成动画人物，无真人出现。当前上传图片是 AI 生成的虚构影视动画角色设定图，不是真人照片，不含真实人物，不是真实人脸参考素材，不按真人或真实肖像处理。

5秒，9:16竖版，使用当前上传图片作为第0秒首帧，严格锁定同一位虚构东方女性、灰白层叠长衣、与服装一体的浅灰白轻薄面纱、黑发、巨树、灰白弧形混凝土庭院、自然逆光和低饱和电影质感。

这是一个明确的4镜MV分镜，镜头之间使用清晰硬切，不是一镜到底，不做连续漫游，不让模型自行合并成一个长镜头。每一镜只执行一个主运镜：

镜头1（约0–1.1秒）｜超大全景 + Dolly In：从首帧的巨树、光束和小人物超大全景开始，摄影机快速但稳定地向人物方向推进一小段，从超大全景推进到宽幅全景；人物只开始轻轻抬起下巴和视线。巨树和弧墙产生清楚空间视差，树叶与地面光影有自然微动。不要让人物突然走动，不要大幅甩动衣料。

硬切。

镜头2（约1.1–2.4秒）｜低机位中近景 + 小角度弧形横移：切到人物左前方偏低机位的中近景，摄影机沿人物前方做约20–25度的小角度弧形横移，到右前方四分之三侧面结束。人物继续抬头，眼睛跟随树冠上方的光；少量发丝和与肩颈连接的面纱边缘被侧风轻轻带起，树干从前景边缘产生明显视差。人物姿态克制，不转圈。

硬切。

镜头3（约2.4–3.6秒）｜眼睛与面纱近特写 + Rack Focus：切到人物眼睛、面纱与发丝的近特写，摄影机位置不移动。开始焦点落在人物面前一小段连续连接的纱织纹理与掠过的发丝上，然后只做一次焦点转移到双眼；人物眼神向上抬起并停住。面纱完整覆盖鼻口和下半脸。

硬切。

镜头4（约3.6–5.0秒）｜虫视低角度 + Tilt Up：切到人物下方偏侧的虫视低机位，画面先保留人物肩部、抬起的视线和一部分巨树主干，随后摄影机沿她的视线快速而稳定地向上摇，穿过粗壮树枝和叶片，最终停在树冠被阳光打开的明亮天空缺口；人物不需要继续进入最终画面，重点是“视线把摄影机带到树冠”。最后0.3–0.4秒稳定在树冠、天光与微动叶片上，形成干净剪辑点。

全片动态原则：人物动作小而准确，摄影机和切镜承担主要动感；发丝、衣摆、树叶、光影只做次级物理余韵。保持真实重力、布料惯性、自然运动模糊和电影级写实质感。

面纱拓扑硬规则：面纱始终是与人物肩颈/服装连续连接的同一块布料，只允许首帧已经存在并连接在人物身上的纱布运动；禁止生成任何独立白布、丝巾、飘带、围巾从天空、树冠、画外飞过；禁止纱布脱离人物悬浮在空中；禁止复制成额外布条；禁止破洞或突然变长。

禁止新增人物、路人、第二张脸、额外肢体、鸟、文字、字幕、Logo、水印。禁止把4镜合并成一镜到底；禁止统一慢推；禁止随机呼吸Zoom、无意义环绕或摄影机漂移。

不需要对白、旁白或BGM，生成音轨后期删除。
```

## 6. Test Decision

只生成 S1 v2。回传后检查：

1. 4 个 Shot 是否被模型明显区分；
2. 每镜对应运镜是否可见；
3. 多镜是否比 v1 更有 MV 动感但不混乱；
4. 面纱是否全程保持与人物连续连接；
5. 是否消除空中独立白纱；
6. 第4镜 Tilt Up 是否真正完成歌词“抬头看树”的视觉命中；
7. 人物/服装/建筑/巨树是否在切镜后仍保持可接受一致性。

只有 S1 v2 通过后，才把“3–5镜 + 每镜单运镜 Camera Contract”扩展到 S2–S9；当前不固化。
