# Face R&D 02｜Healing Tension + Moving Camera｜Closure Receipt

Date: 2026-08-25
Status: `3/3 POSITIVE / CLOSED / PRODUCTION-READY EXPERIMENTAL PATH`
Scope: parallel R&D only; not itself a published MV.

## 1. Test question

Can a fictional adult male character use a strongly degraded / low-information face first frame, allow the video model to complete the face, and still remain usable when the subject moves and the camera also moves?

Secondary questions:
- can the visual world stay bright / healing rather than dark / gloomy while preserving character attraction?
- can moving-subject camera grammar produce stronger source material than the prior default of mostly static people + camera-only movement?
- can safety-sensitive prompt wording be cleaned up without losing the full MV dynamic control skeleton?

## 2. Test set

### S01 — `LEAD / backward tracking`
Subject:
- continues natural forward walking;
- simple towel / hair secondary action;
- only brief small gaze change.

Camera:
- begins in front of subject;
- retreats smoothly on the subject axis;
- relative speed allows distance to shrink slightly.

Result: `PASS / POSITIVE`.

Validated:
- moving subject + moving camera can remain stable;
- low-information face completion remained usable through walking and approach;
- natural locomotion is more valuable than static portrait-only movement for future MV material.

### S02 — `YIELD / diagonal retreat + foreground fabric`
K0:
- hand already very near the camera;
- white fabric already exists in foreground.

Subject:
- continues forward;
- hand clears fabric once;
- no reset / re-reach.

Camera:
- short backward + lateral yield to provide a path.

Result: `PASS / POSITIVE`.

Validated:
- near-camera hand can remain usable when preloaded in K0 and given a short bounded continuation;
- foreground fabric can supply depth / reveal / physical residue without an extra cut;
- actual K0 action phase must outrank the old intended action order.

### S03 — `FOLLOW -> OVERTAKE -> LEAD`
Observed source:
- duration: ~5.04s;
- frame rate: 24fps;
- subject keeps walking on the seaside boardwalk;
- camera relationship changes meaningfully from rear-side observation toward side/front-side relative position;
- subject head / face angle changes while locomotion continues;
- bright exterior geography remains coherent.

Result: `PASS / POSITIVE`.

Validated:
- moving subject + camera overtake is feasible at this complexity level;
- camera can carry the majority of directional complexity while subject action remains simple;
- identity remains perceptually coherent enough for continued production experiments through face-angle changes;
- `OVERTAKE` should be specified as a real translational track, not an in-place orbit.

## 3. Combined conclusion

Face R&D 02 closes at:

`S01 PASS + S02 PASS + S03 PASS = 3/3 POSITIVE`

The combined route is now classified:

`PRODUCTION-READY EXPERIMENTAL`

This means it may be used selectively in the next real song-driven MV with explicit QA and rollback.

It does **not** mean:
- all future characters should remove veils / masks;
- every beat should contain walking / tracking / overtake;
- the same white-shirt / seaside / male visual styling should be repeated;
- R&D success alone proves universal cross-song reliability.

## 4. Director capabilities promoted from this R&D

### A. Camera–Subject Relationship before camera-name
Director chooses viewer position / relationship first:
- HOLD / OBSERVE
- FOLLOW
- LEAD
- YIELD
- OVERTAKE
- DISCOVER / REVEAL

Then define the physical camera move.

### B. Moving subject is now a first-class option
Do not default to:
`static person + wind + slow push`.

When lyric / emotion benefits from travel, approach, departure, discovery or recognition, allow real subject locomotion with controlled camera relationship.

### C. One complexity owner
For a 5s source:
`1 primary subject event + 1 primary camera relationship/move + 1 secondary physical response`.

If camera = M–L, keep head / hands / physics simple.
If subject action = M–L, keep camera to one relationship.

### D. K0 phase continuation
Actual accepted first-frame pixels are the real 0.0s action phase.
Never reset a walking body, near-camera hand, lookback or moving fabric merely to reconstruct an older Director description.

### E. Gait / face-rotation QA
When applicable, add:
- GAIT_STABILITY
- WEIGHT_TRANSFER
- SCREEN_DIRECTION
- FACE_ROTATION_STABILITY
- CAMERA_RELATIONSHIP_ACCURACY

## 5. Face-Degrade path conclusion

Strongly degraded / low-information fictional face first frames can be used as an experimental alternative to veil / mask when exposed facial performance is valuable.

Current acceptance target is perceptual continuity, not forensic Face-ID identity.
Small facial micro-drift can be tolerated if continuous viewing clearly reads as the same fictional character.

Keep both production modes:
- `VEIL / MASK STABLE PATH`
- `FACE-DEGRADE -> FACE-COMPLETION EXPERIMENTAL PATH`

Choose by lyric, aesthetics and stability needs.

## 6. Aesthetic lesson

The early dark rain-night tests were technically useful but visually heavy.
The bright test family showed a more comfortable direction:
- luminous soft daylight;
- low-to-moderate contrast;
- readable face/body shadows;
- open, airy depth;
- fabric / hair / breeze as soft motion.

Reusable concept:
`COMFORTABLE / HEALING WORLD + CONTROLLED HUMAN PROXIMITY / MOTION`.

Do not hard-code seaside or white clothing.

## 7. Prompt-standard lesson

A safety-sensitive wording rewrite must not reduce the full production prompt into a simple cinematic paragraph.

Preserve:
`HARD FREEZE -> FRAME-0 -> STATIC BASE -> ONE EVENT -> BOUND -> MOTION LOAD -> PHASES -> CAMERA -> FEEDBACK -> RESIDUE -> END STATE -> SOUND -> AVOID`.

Translate abstract internal intent into physical actions / distances / gaze / blocking / camera paths.

`SAFE WORDING != SIMPLIFIED CONTROL`.

The next real MV may selectively use these new capabilities when lyric fit is strong.

Priority remains:
`LYRIC VISUAL HIT > LIGHT NARRATIVE CONTINUITY > CAMERA / MOTION SHOWCASE`.

Record:

Cross-song success in that real MV is the next promotion gate.
