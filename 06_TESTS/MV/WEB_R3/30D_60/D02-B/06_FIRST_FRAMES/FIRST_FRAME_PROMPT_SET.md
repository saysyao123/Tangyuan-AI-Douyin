```text
【Negative】
不要第二人物；不要人物已经静止摆好姿势；不要手伸向镜头；不要强烈扭头；不要跑步；不要夸张笑容；不要裸露上身；不要镜面、手机、信件、文字；不要暗夜、雨夜、霓虹；不要裁断头顶或双脚关键动作空间。
```

