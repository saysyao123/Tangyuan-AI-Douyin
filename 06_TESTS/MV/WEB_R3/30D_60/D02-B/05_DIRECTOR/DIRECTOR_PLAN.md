## 1. Director Thesis

This MV is not about a man simply walking away.
It is about **a series of impulses that are repeatedly contained until one final physical release becomes possible**.

The lyrics must remain visible even with subtitles turned off.
Each important verb receives a concrete visual action or environmental proof:

`想 -> 靠近`
`忍住 -> 动作停在边界`
`想说 -> 表达冲动形成`
`算了 -> 手/目光撤回并转身`
`雨停 -> 雨后的最后痕迹`
`风过 -> 一阵风真实穿过`
`舍不得 -> 仍然握住`
`放下 -> 手松开 + 镜头不再追`.

OSS relational-camera logic remains the authored continuity layer:

`LEAD -> HOLD -> YIELD -> DISCOVER -> RELEASE -> STOP PURSUING`.

## 2. Visual world retained from successful attempt

Preserve what the user already liked:

- single fictional East Asian male protagonist;
- bright healing coastal modernist retreat;
- pale limestone / warm-white linen / sea / clear sky;
- warm-white linen shirt + pale trousers;
- restrained male attractiveness from posture, movement, gaze and distance, not beauty-ad posing;
- natural warm daylight, gentle breeze, clean cinematic texture;
- standard square black face-grid first-frame anonymization when the face is readable;
- validated Face Reconstruction execution: first ~1s prioritizes face reconstruction before heavier subject/camera motion.

Do not inherit the previous plan's low source density.

## 3. Material-density policy

This attempt intentionally over-produces edit options.

- Generate 5 new raw sources, each about 5s.
- H-S01 / H-S02 / H-S04 default to 2 visible shots.
- H-S03 uses a justified 3-shot discovery grammar.
- H-S05 uses 1–2 shots, with the final wide held long enough for tail breathing.
- Expected raw visible-shot capacity: 10–11.
- Expected normalized usable ATOM pool: minimum 9 preferred.
- Final 15.386s picture edit should normally select about 7–9 shots, not use everything.
- Existing four prior-attempt clips remain optional supplemental pool only after fresh Dynamic QA; do not force them into the cut simply because they already exist.

The production goal is:
`more usable atoms than required -> select strongest -> trim before regenerate`.

## 9. Camera progression across the whole MV

The camera grammar is not a menu; it is one emotional progression:

1. `LEAD` — receives attraction / longing.
2. `HOLD` — respects restraint.
3. `HOLD -> YIELD` — waits for words, then gives passage when they are abandoned.
4. `DISCOVER / FOLLOW` — reveals time and weather after-state.
5. `RELATIONAL HOLD` — lets attachment remain visible.
6. `STOP PURSUING / WORLD OPEN` — release becomes camera behavior, not only subject action.

## 10. WHY CUT HERE discipline

Internal cuts are allowed and encouraged only when they create an independently useful lyric/edit atom.

Allowed cut motives in this plan:
- action-state change (`approach -> restraint`);
- intention-state change (`almost speak -> abandon`);
- information perspective (`human -> after-rain detail`);
- physical event reveal (`rain trace -> gust`);
- semantic contradiction (`舍不得 -> 松手`);
- final scale release (`continue -> world open`).

Forbidden:
- random montage for pace;
- unmotivated orbit/whip/zoom;
- cuts that introduce new person or new location unrelated to the established coastal world;
- micro-shots too short to read after normalization.

## 11. Generation-load discipline

Per visible shot:
`1 dominant subject/environment event + 1 motivated camera behavior`.

Do not stack complex face change + full-body choreography + aggressive camera move + weather effect at the same moment.
When the face is readable at K0, preserve the validated standard-square-grid Face Reconstruction route and reserve the first ~1s for reconstruction before heavier movement.
