## 0. Production principle

首帧不是“漂亮静帧”，而是每个 production segment 的 `0-second dynamic anchor`。

每张必须同时回答：
1. 这一句歌词最不可替代的视觉答案是什么；
2. 0 秒主视觉事件处于什么起始态；
3. 人物/物体的第一个动作从哪里进入；
4. 摄影机与动作空间是否留够；
5. 动作结束后有什么可持续的物理余韵；
6. 这张与前后镜头在景别、视角、空间、主事件上是否足够不同。

Hard continuity:
- 同一虚构年轻成年东方女性；
- 修长东方杏眼、明确眉眼深度、湿润 catchlight；
- 烟炭黑半透明面纱始终完整遮住下半脸；
- 黑/深炭衣着体系，不做暴露性服装；
- 低频净肌 + 真实微结构；
- 不复刻真实明星身份；
- 无第二真人、无可读文字/Logo/广告；
- 风是 recurring invisible actor，雨是 answering actor；
- 现代诗意生活空间，不是古装、不做重奇幻。

## S01｜0.000–3.000｜如果风会替我说话

Role: `HOOK`
Shot geometry: `EXTREME CLOSE / frontal-oblique`
MMP: `M0 -> M1`

### 0-second anchor
- 极近眼区；
- 双眼是第一视觉中心，但不完全正对镜头，带极轻三分之一偏角；
- 烟炭黑面纱从鼻梁下方向斜侧延展，完整覆盖下半脸；
- 一缕面纱边缘已经处于“即将被风抬起”的张力状态；
- 2–4 根细发丝停在即将横越眼区的位置；
- 冷窗光塑造眼球湿润感，侧后方只有一线琥珀暖边光。

### Dominant event
`风第一次取得发言权。`

### First motion entrance
- 风先抬面纱边缘；
- 约后 0.1–0.3s 发丝再响应；
- 眼球最后轻偏向风来的方向，头不跟。

### Sustainable residue
面纱余摆 + 发丝回落 + catchlight 微位移。

### Composition / beauty target
- 眼型需要比通用 AI 美女更修长、更有眉眼纵深；
- 禁止纯美容棚拍平光；
- 画面要有空气、风和空间，而不是只有眼睛。

### Avoid
- 面纱挡住眼睛；
- 过度浓妆；
- 眼睛放大到非真人比例；
- 直视镜头的网红自拍感。

## S02｜3.000–6.000｜如果雨会替我回答

Role: `RESPONSE`
Shot geometry: `CLOSE PROFILE + REFLECTION`
MMP: `M1 + optional M2`

### 0-second anchor
- 女主贴近雨窗三分之二侧面；
- 真实眼睛位于画面一侧，雨中玻璃反射的第二个“眼”位于另一侧；
- 反射明显是同一人的镜像，不是第二真人；
- 一滴较大的雨珠停在反射眼上方，即将与另一滴汇合；
- 后方很远保留一个暖灯点，空间其余区域偏暗。

### Dominant event
`雨通过破碎反射回答她。`

### First motion entrance
雨滴先汇合下滑，穿过反射眼；随后她真实视线极轻跟随，不转头。

### Sustainable residue
水迹拖尾 + 窗帘呼吸级微动 + 反射轻微变形。

### Avoid
- 玻璃反射生成第二张不同脸；
- 雨滴做成夸张特效；
- 人物正面 Beauty Shot 重复 S01。

## S03｜6.000–8.000｜如果我还会想起他

Role: `MEMORY / ABSENCE`
Shot geometry: `MEDIUM-CLOSE DEPTH`
MMP: `M1 -> M2`

### 0-second anchor
- 女主坐在真实生活感房间边缘，前景人物清晰；
- 画面后方不是男性，而是一处“有人曾在”的暖光空位：空椅 / 半开的门 / 桌边留下的第二只杯垫等，只选一个主符号；
- 一面暗镜或雨窗可把那处暖光弱弱带入人物侧后方；
- 人物没有转头，只是眼睛处于即将看向空位的前一刻。

### Dominant event
`缺席本身成为“他”。`

### First motion entrance
眼球先偏向空位 -> 停留 -> 一次慢眨眼。

### Sustainable residue
空灯稳定、细雨远景、人物呼吸。

### Avoid
- 第二真人/男影/人形剪影；
- 过度道具叙事；
- 把“想起他”拍成哭戏。

## S04｜8.000–12.000｜如果还能一起回家

Role: `HOME / HOLD`
Shot geometry: `WIDE THRESHOLD ARCHITECTURE`
MMP: `light M1 only`

### 0-second anchor
- 人物从近景切到明显更宽的门槛空间；
- 她站在雨湿走廊/旧公寓门口/带屋檐入口，人物占画面较小比例；
- 前景冷蓝灰，远端只有一个稳定温暖的“家”的光坐标；
- 一只手轻贴门框，身体还没有迈步；
- 面纱与外套在走廊风里向“家”的方向产生轻张力。

### Dominant event
`回家不是情侣同框，而是一个可抵达的暖坐标。`

### First motion entrance
远端暖灯由轻微不稳变稳；风先将面纱向内带；人物视线再转向远端。

### Sustainable residue
走廊雨气 + 衣摆/面纱轻动 + 暖光稳定。

### Avoid
- 出现第二人物；
- 过度豪华样板间；
- 人物站得太大，失去“路/家”的空间感。

## S05｜12.000–15.000｜如果梦能模糊真假

Role: `DREAM / AMBIGUITY`
Shot geometry: `SYMMETRIC REFLECTION GEOMETRY`
MMP: `M0 / reflection-driven`

### 0-second anchor
- 人物实体位于一侧或上半区；
- 同一人物通过浅水/黑镜形成单一倒影；
- 实体与倒影的眼睛几乎重合，但有极小错位；
- 面纱结构、发型、服装在倒影中一致；
- 水面/镜面已经处于“极静、下一刻会被破坏”的状态。

### Dominant event
`真假只隔一层会被打破的表面。`

### First motion entrance
一滴雨 / 一圈小波纹 / 一口薄雾破坏眼睛对齐。

### Sustainable residue
波纹扩散 + 倒影逐渐恢复但不完全重合。

### Avoid
- 第二真人；
- 镜像脸型不一致；
- 仙术/发光粒子式奇幻；
- 过度复杂反射造成模型拓扑风险。

## S06｜15.000–18.000｜如果痛能随之融化

Role: `HEALING / MMP-01 CORE TEST`
Shot geometry: `TACTILE CLOSE / EYES + HANDS`
MMP: `M3 -> M4 -> M5 -> M6`

### 0-second anchor
- 近景同时包含双眼、面纱上缘与一只手；
- 人物内眉已处于“即将轻提”的前状态，但没有演满；
- 另一只手位于画面边缘，即将接触面纱脸侧；
- 面纱保持完整覆盖；
- 暖灯透过一小块带水汽的透明玻璃/冰晶状小物形成柔和散射，作为“融化”视觉辅因，不做魔法道具。

### Dominant event
`痛不是靠哭表现，而是从紧绷状态逐渐改变物理状态。`

### First motion entrance
内眉轻提 -> 眉心微收 -> 下眼睑绷紧 -> 手接触面纱 -> 经布料轻压脸侧 -> 短暂加压 -> 松开。

### Sustainable residue
面纱与脸侧回弹 + 水汽/水珠继续滑落 + 眉眼保留短暂 residual emotion。

### Why this is the MMP test
这是全组唯一允许“明显人物物理表演高潮”的段落，用来判断：
- 手部能否稳定；
- 面纱能否真实受力；
- 眼眉错峰表演能否降低 AI 模板感；
- 高级感/治愈感是否仍然成立。

### Avoid
- 捏裸露脸；
- 露嘴/露鼻；
- 夸张疼痛；
- 手部六指/穿模；
- 眼眉动作同时爆发。

## S07｜18.000–20.000｜如果我们还是傻瓜

Role: `TENDERNESS / IMPERFECT US`
Shot geometry: `MEDIUM DOMESTIC STILLNESS`
MMP: `M0 + softened gaze`

### 0-second anchor
- 女主在窗边或桌边，中景；
- 桌上/窗台放两个非常简单的纸风物或不完美折纸，其中一个略歪；
- 两件物体不是人物替身，不带人脸；
- 女主视线停在它们之间，眼神首次明显柔下来，但不笑；
- 面纱仍完整。

### Dominant event
`“我们”由两个不完美但相互响应的物体暗示。`

### First motion entrance
第一只纸风物被小风带动，第二只晚半拍响应；她只用目光感知，不做大动作。

### Sustainable residue
两个物体不同步的轻摆 + 纱帘余动。

### Avoid
- 爱心/情侣摆件等直白符号；
- 甜宠笑脸；
- 第二人物影子；
- 童话化萌物。

## S08｜20.000–24.000｜如果爱不只是童话

Role: `RELEASE / FINAL PEAK`
Shot geometry: `MEDIUM-WIDE DAWN RELEASE`
MMP: `M6 -> M7`

### 0-second anchor
- 雨后清晨外部空间：屋顶花园 / 高处步道 / 树边平台，选择自然且现实的空间；
- 人物从前面封闭空间中走到更开阔环境；
- 暖晨光刚刚从云层后进入，仍保留冷灰雨后空气；
- 面纱边缘被逆光描亮，但透明度不足以看清下半脸；
- 人物眼神仍有一点前段残余张力，尚未完全释然。

### Dominant event
`童话不是奇幻场景，而是真实世界终于出现可触摸的晨光。`

### First motion entrance
短闭眼 -> 睁眼 -> 视线移向斜上远处；同时风把面纱向光的一侧打开，发丝随后响应。

### Sustainable residue
面纱在晨光中回落 + 发丝轻摆 + 雨后树叶/远景空气运动。

### Avoid
- 大笑；
- 梦幻城堡/仙境；
- 金色粒子大爆发；
- 面纱逆光后变透明露出嘴；
- 回头看镜头式网红 pose。

## 9. Set-level differentiation gate

生成后必须整组检查：

| Segment | Primary geometry | Dominant actor |
|---|---|---|
| S01 | 极近眼区 | 风/面纱 |
| S02 | 侧面雨窗 | 雨/反射 |
| S03 | 中近景纵深 | 缺席的暖空位 |
| S04 | 广角门槛空间 | 家的暖坐标 |
| S05 | 对称倒影 | 水面/真假 |
| S06 | 眼+手触觉近景 | 微表演/融化 |
| S07 | 生活中景 | 两个不完美物体 |
| S08 | 中远景开放空间 | 晨光/释放 |

Hard fail if:
- 连续两张只是换背景的人像；
- S01/S02/S06 都变成同样眼睛特写；
- 室内占比过高导致没有空间呼吸；
- S08 仍然像 S01 一样压迫封闭；
- 面纱材质/颜色/覆盖范围漂移。

## 10. Generation order

不一次盲生 8 张。

### Calibration batch A｜3 images
1. `S01 HOOK` — 测人物辨识度 + 风/面纱；
2. `S06 HEALING` — 测 MMP-01 静态动态入口 + 手/面纱物理可执行性；
3. `S08 RELEASE` — 测人物在开放环境中的统一性 + 治愈上限。

Batch A QA PASS 后，再生成：
`S02 + S03 + S04 + S05 + S07`。

### Why
三张覆盖最关键的三类难点：
- 极近人物质量；
- 微表演与物理动作；
- 开放空间/治愈释放。

如果这三张不能同时成立，直接生成完整 8 张只会放大返工。
