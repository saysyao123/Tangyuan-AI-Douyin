## Continuity assessment

### What is continuous

- same apparent character identity;
- same hair, age impression, skin tone and wardrobe;
- same cool light-gray background and high-key close-up visual language;
- emotional progression is coherent from uncertainty/confirmation into proactive camera interaction.

### What is NOT frame-continuous

The boundary is not an optical seamless continuation:

- first segment ends with a three-quarter pose and one hand touching the cheek;
- second segment begins front-facing with both hands framing/touching the face.

Therefore the current evidence supports **narrative / identity / style continuity**, but does not support a claim of exact last-frame → next-first-frame continuation.

## Architecture inference

The observed Dola Expert Mode behavior is consistent with an orchestration layer that:

1. accepts a 30-second intent;
2. decomposes it into two sequential 15-second generations;
3. carries continuity instructions/scene context into the second generation;
4. returns two separate 15-second files.

This is materially different from proving that a single underlying video model natively generated one 30-second clip.

## Product implications

This result changes the 30-second Gate definition:

- Do not treat `30s` as synonymous with `one native 30s Seedance 2.5 call`.
- Add a separate concept: `expert_orchestrated_30s = 2 × 15s`.
- Judge quality on identity/style continuity and seam quality separately.
- Do not spend additional generation quota merely to rediscover this behavior; inspect existing task/history UI first.
