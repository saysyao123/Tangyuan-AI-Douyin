# Portable V1 — First Run

Default first-run vault password: `Tangyuan-Portable-2026!`

This default exists only for initial convenience. It is public in the source code and is therefore **not** a long-term security boundary. After confirming the application launches and your Dola account session works, change the vault password from the desktop Settings/Vault panel before storing important long-lived sessions.

The workbench does not automate account creation, CAPTCHA, SMS verification, quota/entitlement bypass, or provider restrictions. 30-second generation remains experimental and is only used when the currently logged-in Dola account exposes that option normally.
