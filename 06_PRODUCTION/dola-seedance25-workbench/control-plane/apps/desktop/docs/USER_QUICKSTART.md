# Dola Seedance Portable V1 — Quick Start

> RC2 修复重点：不再使用 Electron 中不可靠的浏览器 `prompt/alert/confirm` 对话框。添加账号、修改保险库密码、确认操作都改成软件内置面板。

1. 解压 ZIP 到一个普通可写目录，例如 `D:\AI\DolaWorkbench-RC2`。第一次验证 RC2 建议使用新目录，避免旧 RC1 的临时运行态干扰判断。
2. 双击 `Dola-Seedance-Workbench-Portable-*.exe`。
3. 首次运行会自动建立并解锁本地保险库，预设密码为 `Tangyuan-Portable-2026!`。这是首次启动便利密码，不是长期安全密码。
4. 如果你准备长期使用，建议在正式添加账号前点顶部“修改保险库密码”，通过软件内置密码面板改成自己的密码。
5. 点击左侧“+ 添加 Dola 账号”，在弹出的软件内置窗口填写名称并点“创建并打开登录页”。中间会打开该账号专属 Dola 会话。
6. 在中间 Dola 页面由你本人正常完成登录。程序不会收集 Google 密码、TOTP、短信验证码，也不会自动注册账号。登录完成后可点顶部“检查登录”。
7. 右侧支持“文生视频 / 图生视频”。图生视频时点击“选择首帧图片”，使用 Windows 原生文件选择器选择 PNG/JPG/JPEG/WebP。
8. 选择 5s/10s、比例并输入 Prompt。通常直接点“创建并开始”；如果只想排队，点“仅加入队列”。
9. 如果任务进入 `observation_wait`，程序会先做一次“只恢复观察、不重新提交”的恢复；仍未拿到媒体时可点“恢复等待中的任务”。这一步不会再次点击 Dola 的生成按钮。
10. 成功解析并下载的 MP4 保存到程序旁的 `data\outputs\`。调试/证据文件在 `data\debug\`，项目/任务元数据在 `data\projects\` 和任务数据中。
11. 5s/10s 是当前主验证目标。只有当前 Dola 页面/账号本身正常提供 30s 时才选择 30s；程序不会伪造 entitlement、绕过 quota、CAPTCHA、MFA、地区限制或服务端拒绝。
12. 正常关闭程序时，已打开账号的 Chromium 登录态会重新加密写入 `data\vault\`。如果 Windows 文件句柄导致明文 Profile 无法安全删除，程序会阻止“假装安全退出”并要求恢复/重试。

## RC2 界面逻辑

- 左侧：账号池。只负责账号别名、登录状态和切换。
- 中间：当前账号唯一可见的 Dola 页面，用于首次登录、人工检查和调试。
- 右侧：Seedance 任务。支持 T2V / I2V、时长、比例、Prompt、创建并开始、仅排队和恢复观察。
- 顶部：当前账号登录检查、刷新、清除会话，以及保险库密码/锁定操作。

## 目录

- `runtime/`：临时控制与解密后的运行态；程序运行时使用。
- `data/vault/`：加密后的账号 Profile。
- `data/accounts/`：非敏感账号元数据。
- `data/projects/`：项目/Job 状态。
- `data/outputs/`：生成后成功解析、下载并通过轻量 MP4 校验的文件。
- `data/logs/`、`data/debug/`、`data/backups/`：日志、调试证据和备份。

移动到另一台电脑前，先正常退出并备份整个 `data/`。跨机器登录态是否继续有效最终由 Dola/Google 的安全策略决定，必要时会要求重新登录。
