# 仙剑98 → 书籍游戏化基线研究 V0.1

**定位：第一阶段优先按《仙剑奇侠传98柔情篇》完整的经典RPG机制制作新小说的游戏，不重制原版，也不主动改玩法。**

## 原始目标
把书中的人物、世界、剧情、事件和美术转为可以玩的独立故事游戏，复用一套通用仙剑式RPG引擎；第二本书不改核心引擎，只替换内容包。优先 GPT Plus/Codex + 网页端，免额外付费订阅。

## 冻结要求
- 保留斜视角地图探索、NPC自动/触发脚本、队伍跟随、场景切换。
- 保留三人作战、角色属性/成长/装备/技能、五灵、异常状态、回合菜单与合击/援护。
- 保留剧情演出、分段对话、物品、商店、音频、存读档和开场/结局。
- 人物设计继承“性格 × 叙事功能 × 可用能力 × 出退场变化”四层模型。
- 不直接复用仙剑的角色、画面、音乐和剧情到将发行的新游戏；使用公版、原创或获授权书籍及美术。
- 内部为兼容性可以改数据结构，但不得在无回归验证的情况下改变玩家可感知的经典玩法。
