## 2. 从原作学到的五种可复用设计逻辑

1. **角色首先是现场小人，而非头像缩小。** 轮廓→体型→服装大色块→头饰/工具→局部折光；在 46–50px 限制下，不能寄托于精细脸部。
2. **4斜向是不同几何视图，不是镜像同一姿势。** 背面能见头发/背包、侧面肩颈与衣摆、朝前有脸部；脚底锚点不变；三步帧0/1/0/2要出现真实换脚与重心。
3. **场景先解决建筑体积、寻路与视觉层，再上材质。** 墙/地/窗/床/桌区分前后层和接触面；房间宜用少量一眼可辨的地标，而非全景堆物。
4. **道具在空间中拥有厚度与作用。** 物件透视跟2:1地面配合，桌脚/床脚固定，阴影落在接触点；点击/碰撞体与视觉透明区域分开。
5. **NPC差异源于社会身份和生活功能。** 用发型、肩宽/腰身、衣服层次、配色/行动道具和站姿区分，不是同一身形换衣服；非关键NPC也不能各自站在不同艺术时空。

这些是从截图/结构抽出的**设计规范**，不是原作者的官方内部美术手册。

## 4. 旧屋真实道具及九图的美术统一原则

- **home-room（样板）：** `bed` 床褥厚度、`tv` CRT电视与柜体、`kitchen-cupboard` 木柜、`moonlit-room-window` 旧窗/窗帘、`winter-coat-by-wall` 冬衣架、`meal-table` 汤面桌、`washbasin` 水盆、`room-lamp` 暖灯；要求各自材质、接地与相互遮挡统一，保持原锚点/脚印/交互。
- **night-road / snow-yard / courtyard：** `winter-tree` 雪树、`snow-wood` 柴堆、`stone-lantern` 石灯、屋檐/围栏；雪地颗粒抑制、地表接缝和出入口标志先于装饰堆叠。
- **fair / backstage：** 台口、观众/NPC、货摊、后台工具，以密度/功能区分，不让摊位反向遮挡关键通道。
- **street / night-shop-room：** `rental`、`night-shop`、店内货架与收银/柜台要有同一建筑透视逻辑。
- **mind-tree：** 幻想效果可以独立做材质，但人物尺度、脚底锚点、点击反馈沿用全局游戏规范。
- 上述是类别级规范，**未对九图全部现状复核或修改**，不把材质原则等同逐图验收。
