# T19 P1｜旧屋样板资产与 P2 最小工作包（非正式生产版本）

基线：T18 私有 Site 及 GitHub `evidence/T18_NAVIGATION_20261017/01-room-enriched.png`。P1 的静态草样文件仅在本轮对话 `T19_P0_P1_art_sample.zip` 内；**不假装本仓库已经包含未上传的图像或源码**。

## 目标美术（唯一候选）

320×200 逻辑像素，4× nearest 复核；暖木色／冷夜窗／局部灯光；像素硬边，不采用写实古装设定或另建房间。成年主角保持深色冬装（hero：36×56画布，主体约50像素高），孩童同伴保持浅色上衣红棕围巾（child：32×44画布，主体约38像素高）。原生共享256索引色及四向×三姿势在P1**未验证**。

## 本轮反馈门与必要验证

P1：用户对 **视觉方向、人物识别和原 320×200 小尺寸可读性** 明确认可方可继续。未确认时只补修样板；不批量开发。

P2（批准后）：仅围绕 `home-room` 原生资产分别替换；带脚点/不透明命中/遮挡数据、保留地图脚印；针对 2 主角四向走停、点击门/餐桌/水盆、键盘接管、入场镜头和真实旧档卡位恢复做**受影响定向测试**。不重跑抽奖、战斗、完整剧情套件。

数据界限：本轮草样是静态研究图，不是 Type PAL 运行截图，未宣称索引色板、渲染程序、交互、行走或性能通过。
