- 原始MKF仅私有研究，公开GitHub只记录数量/尺寸/方法；不上传原始图片、音频或书籍正文。
- 新美术采用独立GPT生成泛用人物/道具，不用PAL图片作生成参考。
- AI图集会出现重复步姿/错朝向，不能直接当合格帧。导入只选核对的站姿，按显式方向映射及受约束步行动作生成原生序列；固定画布和脚底，不逐帧缩放造成呼吸。

- 仅显示平滑覆盖同伴/移动NPC；逻辑坐标、阻挡、事件触发、SAVE12保持官方机制。
- 本轮公共CI用原创脱敏内容；实际私有配置用官方校验与逐项机制比对。追加新变化的测试，不重跑P0/T11/T12已通过全套。
