# T1.5 场景与动态故事设计

本轮把开篇的事件从摘要对白展开为原生场景演出。公开工程使用原创替代角色和文本；私有试玩绑定用户提供书籍的开篇两章，逐事件账本留在私有源码内。

| 场景 | T14 | T15 | 空间用途 |
|---|---:|---:|---|
| 庙会 | 12×12 | 32×28 | 摊位、二十名观众、穿行通道、前排与舞台、侧台入口 |
| 后台 | 12×12 | 24×24 | 幕后堆箱、表演者、四名来人、撤离路线、目击者 |
| 归途 | 12×12 | 30×24 | 旧平房街线、拦路交谈、离开后回望、返家路口 |
| 旧院 | 12×12 | 32×26 | 一层旧房、矮墙菜地、药锅蒸汽、邻居和家门 |

尺寸采用 Type PAL v4 地图单位，不能直接当作常见正交瓦片数。地图大小服务于镜头与路径；保留路侧景观和可碰撞边界，剧情落点布置在地图内部。

## 与仙剑原生内容的对照

固定上游 `IllegalCreed/type-pal@f98d0ddd89ebdee7b04502ee35de26ee82c6d246` 的商业项目 `map-012.json` 为64×128。`s003.json` 2338–2370使用 moveEntity/wait 编排倒地后走近查看。这些内容说明空间与事件可以精细组织，不说明扩大到相同尺寸就会更好。本轮借鉴分区、走位、停顿、聚焦与状态后果，全部画面使用自制资产。

- 舞台：走到人群前排，表演者进场，红蓝火燃起/收起/重燃，带尾火球飞向观众后消散，主角短暂反应，谢幕退场。
- 后台：来人走近、针影、表演者倒地、解释、两人带离与其余人撤离。合成搬运精灵表达并行人物，避免改动原生脚本并发语义。
- 归途：交谈后的走离与回头，以及伙伴约定。
- 小院：药锅循环蒸汽、孩子蹲姿与还原、绕开邻居走离、门前收束。

cameraPan 的 dx/dy 是每帧位移，本轮按总量计算；结束 cameraSnap。moveParty/moveEntity 绕过玩家碰撞，必须明确写安全路线。任意交互侧进入时，通过不可见位置探针与原生 entitiesNear 条件选择逐格绕人路线，不增加引擎 API。临时效果都显式隐藏；动作退出前停止；孩子换姿完成后恢复原精灵。

## 美术与边界

GPT 生成冬季旧平房与黑衣人物四向站姿，统一调色后转入原生RLE。步态、蹲姿、倒地与搬运是在原生像素素材上制作的姿势帧；没有把一张整场大图当地图。旧平房替换原来偏华丽的住宅。背景仍有重复地块，普通杂耍仍为简述，人物动作不是完整骨骼表演；当前是开篇精修小阶段。

新项目 `book-pilot-cinematic` 与 `/chapter/` 使用独立存档范围。旧 `/pilot/` 与原创主工程继续提供比较和旧进度。禁止以修改存档坐标兼容全新地图。
