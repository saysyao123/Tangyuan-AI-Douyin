# 角色与剧情导演：仙剑式设计继承

## 仙剑人物学习角度（设计抽象，非原版数值复原）
- **李逍遥**：玩家视角，从日常生活迈入超常世界；成长、探索、行动动力统一，事件推动人物变化。
- **赵灵儿**：人物身份直接关联世界谜团、核心使命和情感风险；剧情与游戏能力不是两条孤立曲线。
- **林月如**：清晰意志与语言风格，人物冲突形成行动与选择的外部推力，不是同伴数值替身。
- **阿奴**：特殊地域和文化接入，毒蛊技能凸显“人物来历→玩法能力”的对应关系。
- 这些是分析经典叙事功能；其他作品绝不直接复制人物名字/设定/造型。

## 新书每一个重要人物的最低七要素
1. 原著事实出处 chapter_id+简短定位，标明 source_fact / reasonable_inference / game_adaptation。
2. 人物角色：主角、同伴、叙事NPC、敌对、关键导师、商店、支线等，可多重。
3. 目标、秘密、价值判断、外部阻力与不可逆的变化。
4. 与其他角色的方向性关系、冲突事件和变化节点；不凭空添加成书籍正史。
5. 四种形态：对白形象、地图精灵（走/停/朝向）、战斗形态、成长面板；NPC可不具战斗形态，但应有行为。
6. 战斗定位：武器/技能/装备/弱点/状态抗性/升级学招；剧情实力增长必须映射游戏进度。
7. 入队/离队、援护/合击、特殊剧情演出和资源一致性验收。

## 从“阅读”转换到“游玩”的剧情编排公式
**文本事实 → 戏剧冲突 → 玩家可行动目标 → 探索线索 → 角色反馈/战斗 → 世界状态变化 → 下一事件**。

每个章节至少要标：
- 玩家现在为什么必须行动（即时目标）
- 玩家在哪里行动（场景）
- 能与什么互动（NPC、物品、敌人、环境）
- 什么条件会放行/阻断（flag、道具、队伍、关卡）
- 玩家获得什么可见反馈（对话、奖励、动画、数值、地图变化）
- 原文依据与改编新增部分的边界

默认一条主线，有必要时有局部支线。不把严肃原作强改成随意分支大结局；小说明确发生过的情节优先保持事实，允许“成功路线不同、结果同归”的玩家选择。

## 制作角色资产规范
每个 playable 角色：固定设计卡 + 头像 + 四方向地图动作（或基于一致动画帧）+ 战斗待机/攻击/技能/受击/倒下等帧 + 声音风格；同角色同场景色彩/比例/发型/服饰恒定。先批准样张再规模生产，AI图像不能自动当作独立游戏精灵。

## 口吻与自然对白
保留原著人物差异，不把所有 NPC 写成同一AI口吻；交代背景以行动和场景为主，短对话承载人物性格与任务反馈，不以长文本替代游戏内容。
