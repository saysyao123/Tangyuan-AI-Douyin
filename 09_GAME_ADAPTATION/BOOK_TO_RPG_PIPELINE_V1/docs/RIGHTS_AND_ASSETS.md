# 权利、原著追踪与美术版权

- 用户上传的商业游戏《仙剑98》作为合法技术研究参考，禁止将其 EXE/DLL/MKF/MIDI/AVI/人物/对话原文上传公开GitHub。项目的研究档案只保留机制抽象和源码链接。
- SDLPAL与Type PAL代码 GPLv3；RPGJS v5 MIT。二次使用代码必须遵守相应许可证，不能把原版游戏资源当作GPL素材。
- 对书籍先判定为：用户原创、明确授权、已进入公版的版本、公版原文但译本有版权、授权不明/受保护。权利不明时仅做内部概要/独立原创试验，不发布复制文本/特有角色设定。
- 各个图片/音乐/字库/配音都须有 `asset_id`、`source_type`、`license_status`、`generated_for` 和风格一致性验收；AI生成也须检查权利与来源。
- 后续真正公开发行与商业化，单独做一次版权许可、音乐/字体许可证、游戏宣传与第三方依赖审查。
- 新创作尽量以角色造型、世界观和叙事为源生成原创素材，不直接模仿仙剑的受保护视觉素材。
