# T32 R2｜第一幕美术继续收口

本轮承接 T32 首次发布，不是扩展剧情。最终用户审美仍待确认。

## 本轮改动

- 八张高清对白头像与现有世界精灵统一：主角、孩子、摊主、邻居、问路青年、访客、看守和演员。灰发邻居沿用当前人物设定；没有另发明人物身份。实际第一幕说话的六类角色通过原生 actor→portrait ID 接入。访客和演员只提供资源，没有捏造新对白。
- 每张原图 256×288，但对白中固定绘为原来的 64×72 逻辑尺寸；姓名、正文起点、分页和输入不变。其他幕与缺图时仍用原资源。
- 后台两面墙各有不同功能：戏服/面具/镜子与门窗/茶具/毛巾，梁柱、顶梁切面与墙脚完整。新墙按原墙的 2:1 平面投影，不移动原生脚点。门只是背景服务门，不新增路线。
- 后台箱子移除积雪，户外箱子维持原样；不改任何实体坐标或命中区域。

## 验收范围

本轮只复测受改动影响的实际对白、高清固定尺寸、后台倒地/抬走与读档；增加 Chromium、Firefox、WebKit 引擎的定向实机验证。不是物理手机或 Safari 应用测试。

原先从空存档到归家的完整九项通过证据继续保留（Run39088306145）。第一幕项目文件与固定 T30 基线逐字节比较，证明剧情、地图、碰撞、SAVE12 没有因美术改动而变化；不重复跑不受影响的旧完整套件。

## 原始美术要求

对照 T19 V2：像素 RPG 人物身份、统一冬装、少噪点地面、建筑体积、真实脚底接触、前后遮挡及小尺寸可读性。禁止拿概念图代替游戏运行图。所有审查图片必须出自实际引擎，所有通过结论附对应运行记录。

结果与发布固定版本以 T32_PROGRESS.md、evidence/T32_20261018/RELEASE.json 为准。

## WebKit 临时会话失败及处理

Run39093310372 中 Chromium / Firefox 各五项 PASS；WebKit 头像显示与摊主对话 PASS，但在导入原生存档时，缩略图 Blob 的 IndexedDB 写入被临时隐私会话拒绝。因此该运行未发布。

这是实际观察到的上游限制，见 WebKit #156347 与 Playwright #42795（https://bugs.webkit.org/show_bug.cgi?id=156347 ，https://github.com/microsoft/playwright/issues/42795）。后续使用正常持久会话验证 WebKit；不修改数据库、缩略图格式或 SAVE12，不用存储模拟掩盖失败。沿用已通过的 Chromium / Firefox 截图和 JSON，逐字节比较新构建 chapter，避免重复它们的通过测试。隐私模式存档限制仍保留在交付边界。
