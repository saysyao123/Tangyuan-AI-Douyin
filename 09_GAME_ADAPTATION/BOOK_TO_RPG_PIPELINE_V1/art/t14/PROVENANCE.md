# T14 original art sources

Generated with the built-in GPT image tool in this session, from original generic winter characters and props. No PAL game pixels or book pages were used as image-generation inputs. GPL-3.0 distribution alongside this project.

Normalized indexed PNGs are the editable game art inputs. catalog.json defines the shared palette and fixed frame contract; prepare_art.py and art.ts convert these to official compressed RLE. Selected full-resolution atlases are retained with the private Site source.

Four standing character views are audited in native order SW, NW, NE, SE. The boy NW view is an explicit mirror of the correct NE source. Generated walking columns and a correction attempt were rejected for repeated feet/wrong orientation. Native three-pose leg/arm rig supplies the actual walk sequence. Props keep their largest connected subject to remove neighboring-cell debris.

No claim of matching the full artistic complexity of PAL98. Current maps use 32 authored ground variants and selected independent props; bespoke map composition, more NPC animation and stronger cinematic blocking remain later work.
