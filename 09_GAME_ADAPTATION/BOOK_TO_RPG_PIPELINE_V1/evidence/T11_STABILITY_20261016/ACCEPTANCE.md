# T1.1 验收范围

本轮保持像素风、原创剧情、双场景、战斗规则、任务和存档协议不变。

验收分开记录：

1. 旧输入实现在丢失 keyup 的 blur/pagehide/visibilitychange 三种场景失效，修复后通过。
2. 新增显示层位置插值，核对画面位置细分增加、逻辑坐标仍按原节拍，不篡改碰撞/存档。
3. 同一 CI 浏览器、4 倍 CPU throttling，对照原物理缓冲与轻量缓冲；分别记录 P95、均值和画面位置样本。不能用减少缓冲像素代替帧率实测。
4. 真实按键失焦后停步；快速开关菜单；连续快速保存后读回有效世界；加载提示只在真实 ready 后消失。
5. 引擎显示/输入修改后复测原完整故事与存读档；保存按钮并发保护修改后复测编辑目录关闭重开及真实试玩。
6. 发布包运行文件与 CI SHA256 对齐，验证 ZIP 完整性；原 URL 更新，保持访问范围和存档 projectId。

具体结果由 stability.json、story-regression.json、editor-regression.json 和正式发布记录给出。只有以上对应测试实际 PASS 才记完成。

边界：短时连续帧与压力回归不等于长期无内存泄漏证明；CI Chromium + 模拟慢 CPU 不等于所有用户电脑/手机实测。OS 原生文件夹授权仍由用户手动完成。
