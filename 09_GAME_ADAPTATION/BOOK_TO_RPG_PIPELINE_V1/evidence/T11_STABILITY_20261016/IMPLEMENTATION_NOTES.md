# T1.1 流畅度与稳定性修复

用户反馈：像素风可以保留，需要细化流畅度与稳定性。保留剧情、玩法、content22 / SAVE12 和 Type PAL 引擎。

已实现：
- 显示层 80ms 位置插值；不写角色逻辑坐标、碰撞、任务和存档。交互/传送/读档/跨场景立即对齐。
- 320×200 逻辑像素不变；默认物理缓冲从 1280×800 降为 640×400；仍按原像素缩放显示。`?quality=sharp` 可选原物理分辨率。
- blur、pagehide、visibilitychange 清空 held 和 pending 输入；页面触屏指针 cancel / capture loss 释放按键。
- 正式包去除上游 __reforge 可变世界调试入口，保留只读验收快照。
- 加载状态、慢加载提示、显式重试；只有真实引擎 ready 才移除加载层。
- HUD 按状态变化更新，修复从结局读回旧存档时标题不复位；避免结束后每 300ms 重写 DOM。
- 对白保存按钮同步锁防连点，保存期间禁用修改与试玩；提示根据真实脏状态报告保存结果。

本机：18 项输入/位置定向单测通过，reforge/editor TypeScript 检查通过。真实浏览器与 CPU 对照结果另附 JSON，不把物理缓冲下降 75% 误称为 CPU 或帧率改善 75%。
