# 用户《仙剑98》RAR 实际结构审计（2026-10-16）

> **方法**：仅从用户上传的 RAR 容器中只读提取 Sss.mkf、Data.mkf、M.msg、Word.dat 供本次本地分析；未运行 Pal.exe、Pal.dll；仓库里不提交原始版权字节。

## 已经用本次上传的具体资源实际验证（A）
- RAR 内实际读出：`Sss.mkf` 575270 B，`Data.mkf` 63978 B，`M.msg` 224455 B，`Word.dat` 5650 B。
- `Sss.mkf` 5 块：`162464 / 2360 / 7910 / 54056 / 348456` 字节；每块符合外部偏移表的合法边界。
- 按 SDLPAL 的事件对象(32B)、场景(8B)、对象(14B)、脚本记录(8B)结构作候选计数：**5077、295、565、43557**。这些数字是字节长度与已知结构除法结果；尚未逐条验证记录语义。
- 剧本操作码第一个16位字段经完整扫描：**160 种不同的操作码取值（包括0xFFFF）**。 `0xFFFF` 出现13519次；非该值共有30038条。**不能未查解释器就判定这些全是有效游戏指令或其余全部无效**。
- 频次前12：`FFFF:13519, 0000:3883, 0005:2675, 0009:1999, 003D:1544, 0049:1374, 003C:1307, 0001:1190, 0046:1065, 0015:915, 0050:908, 0059:883`。
- M.msg 关联的32位文字偏移表有 **13514项**，索引单调非减，最后偏移 **224455** 与实际 M.msg 长度完全相等；前后相邻区间非空 **13510**，空区间3。
- `Word.dat` 5650B 按已知10B定长条目划分为565项，和 Sss 的565个对象候选数量一致；没有在本仓库保存这些文字。
- `Data.mkf` 有15个外层 chunk，大小：`378,10780,3800,900,3328,696,400,0,0,25532,17478,40,282,100,200` B。
- 以上统计可用不依赖付费API的 **`tools/pal98_audit.py`** 再跑，禁止读取或公开原始文件。代码只输出计数/哈希/索引关系/opcode频率，不输出脚本正文、字幕或画面。
