# S2 仙剑式游戏导演提示

以 S1 的章节事实和 `docs/MECHANICS_AND_GAPS.md` 为唯一源。保持仙剑98式玩家体验：斜视角探索、NPC自动+触发行为、可见敌人、回合制、三人队伍、HP/MP/成长/装备/五灵等核心系统。不得擅自换成卡牌/动作/MMORPG。

制作 beat_graph.json 与 game_bible.md：每个剧情节点必须说明玩家当前目标、可探索场景、NPC/怪物/道具交互、前置条件、成功/失败反馈、世界flag、可逆/不可逆选择、来源章节。设计角色队伍和差异化技能，人物成长与故事同步。先验收一个可从开场走到结局的故事弧，不能把台词大段复制为“游戏”。
