# MV Visual Language Bible v0.1

Status: TRIAL
Date: 2026-09-03
Purpose: standardize the visual language for Dola Expert + Seedance 2.5 MV material without directly imitating any living creator.

## 1. Target aesthetic

The target is a hybrid visual system, not a named-artist style:

1. LIVING_NATURE — healing, tactile natural motion, weather as a living presence.
2. LUMINOUS_EMOTION — sky/light/weather/reflection carry emotional meaning and surreal transitions.
3. MONUMENTAL_CALM — epic scale, restrained palette, strong spatial depth, slow deliberate camera.

Production shorthand: HEALING_SURREAL_EPIC.

## 2. Core visual principles

### 2.1 Nature is an actor
Use wind, rain, cloud, steam, water, grass, cloth, dust, petals and reflected light as active performers. Motion should have one dominant environmental cause and readable physical response.

### 2.2 Supernatural events begin from ordinary reality
Start from a believable calm world. Introduce one anomaly. Escalate it. Reach one visual peak. Settle into a new stable world.

### 2.3 Scale before spectacle
A powerful frame should read through foreground/midground/background, subject-to-world scale, negative space and light direction before adding particles or transformation effects.

### 2.4 Light must have a source and a job
Prefer motivated dawn, sunset, overcast skylight, reflected water light, indirect window/light-well illumination, mist diffusion or practical warm lights. Light guides attention and emotional phase; it is not decoration.

### 2.5 Color is restrained but deep
Avoid rainbow spectacle by default. Use a dominant atmospheric family plus subtle local deviations. Depth can be created by light/color separation between foreground, midground and background.

### 2.6 Camera observes first, reveals second
Comfortable MV motion prioritizes controlled push, drift, track, rise, reveal or passage. One primary camera move per beat. Camera does not constantly prove that it is moving.

## 3. Composition grammar

Default 9:16 frame:
- foreground anchor: reflection, foliage, cloth, architecture edge, mist or shadow;
- midground event: primary lyric visual event;
- background world: sky, mountain, architecture, ocean, desert, cloud or light source;
- one intentional negative-space zone;
- human figure optional and usually small/medium unless lyric requires intimacy.

Preferred depth pattern:
foreground shadow/detail -> readable midground -> atmospheric luminous background.

## 4. Light families

### DAWN_PEARL
Cool pearl ambient light + tiny warm edge. Use for healing, awakening, recovery, solitude.

### MAGIC_HOUR_GLOW
Low sun / twilight gradient + bright sky-to-ground contrast. Use for yearning, memory, encounter, transition.

### OVERCAST_LUMINOUS
Soft broad sky, wet surfaces, restrained highlights. Use for rain, reflection, quiet sadness, tenderness.

### INDIRECT_MONUMENTAL
Strong directional bounced/indirect light entering large architecture. Use for awe, destiny, scale and surreal sacred spaces.

### NIGHT_WARM_ISLAND
Cool dark environment + one or a few warm practical light islands. Use for loneliness, waiting, remembrance, shelter.

## 5. Motion families

### BREATHING_WORLD
Small cloud/fog/water/foliage motion; almost-static camera. Healing baseline.

### ONE_FORCE_SYSTEM
One physical cause drives multiple elements consistently: wind -> cloth + fog + water + leaves.

### LUMINOUS_REVEAL
Camera approaches a reflection/light boundary; hidden world or visual meaning is revealed gradually.

### SCALE_REVEAL
Begin with human/object scale, slowly reveal vast architecture/landscape; person becomes small against world.

### WORLD_TRANSFORMATION
Ordinary state -> anomaly -> escalation -> threshold crossing -> stable transformed state.

## 6. Camera grammar for 15s Dola Expert MV

Default 15-second arc:

0-4s OBSERVE / ESTABLISH
- let the viewer understand space;
- low motion load;
- establish light, weather and visual rule.

4-9s AWAKEN / ESCALATE
- one environmental or spatial relationship strengthens;
- camera performs one deliberate move.

9-13s REVEAL / PEAK
- one primary visual event reaches its strongest readable state;
- use scale, light, reflection, occlusion or spatial passage rather than random effects.

13-15s SETTLE / RESIDUE
- no new hero event;
- camera decelerates or locks;
- leave physical residue: fog, water, dust, petals, cloth, light.

## 7. Lyric-to-visual mapping

Use this order:

LYRIC / EMOTION
-> VISUAL THESIS
-> WORLD
-> PRIMARY FORCE OR ANOMALY
-> CAMERA RELATIONSHIP
-> VISUAL PEAK
-> CLEAN END

Examples:
- longing -> distant sky/light across unreachable space;
- memory -> rain/reflection/refracted warm fragments;
- disappearance -> world motion stops / light swallowed by fog;
- dream -> reflection or scale logic detaches from reality;
- release -> wind clears cloud/fabric/petals and opens space;
- loneliness -> tiny figure in large calm architecture/landscape.

## 8. Prompt rules

Default prompt should express:
1. Seedance 2.5 / 15s / 9:16 / reference role.
2. One-sentence lyric intent.
3. World + light family.
4. One primary visual event.
5. 4-phase state chain.
6. One primary camera grammar per beat.
7. Physical feedback / residue.
8. 0-3 hard constraints only if necessary.

Do not use living creator names as generation-style instructions. Translate inspirations into the abstract visual language above.

## 9. K0 / storyboard rules

A K0 is not only a beauty frame. It must contain:
- readable spatial depth;
- a dominant light source;
- visible motion entry;
- physical elements capable of response;
- room for the camera/event to develop.

For 15s transformation beats, prefer a 4-state storyboard when a single K0 cannot communicate the future spatial states.

## 10. Acceptance

A generated 15s source is successful when it provides:
- LYRIC_VISUAL_HIT >= 8/10;
- at least one 2-5s visual peak;
- >= 8 usable seconds OR one exceptional >= 4s peak plus clean supporting material;
- comfortable camera motion;
- coherent light/weather/physics;
- editor-usable end state.

Do not reject a clip only because all 15 seconds are not equally spectacular.

## 11. Reference basis

This trial language was abstracted from publicly discussed principles around animation layout, weather/light-based emotional imagery, natural-light cinematography, large-scale framing and depth construction. Named films/creators are research references only; production prompts should use the abstract language in this file.
