# HYPERFRAMES Semantic / Text / Anchor Addendum v1.1

> 适用：`HYPERFRAMES_EXPLANATION_HARNESS v1.0` 的补充硬规则。  
> 优先级：若本文件与旧 Harness 示例冲突，以本文件为准。  
> 核心：**逻辑正确 > 一眼读懂 > 文字突出 > 资产美观 > 动画复杂度。**

---

# 1｜Semantic Truth Gate｜先证明逻辑，再画动画

任何 HyperFrames 场景进入视觉设计前，必须先写清 5 个字段：

```text
Teaching Truth：这段真正要教什么？
Entities：有哪些对象真实参与？
Invariant：什么东西没变？
Changed Variable：真正改变的变量是什么？
Consequence：变量改变后，结果为什么变化？
```

禁止把以下不同语义混为一谈：

- 替换 Replacement
- 顺序 Reorder
- 延迟 Delay
- 移除 Remove
- 增加 Add
- 过滤 Filter
- 分流 Route
- 锁定 Lock
- 校验 Verify

**动画动作必须与真实语义一一对应。**

例如：
- 原逻辑是“晚一点介入”，禁止画成“永久移除”。
- 原逻辑是“改变先后顺序”，禁止画成“A被B替换”。
- 原逻辑是“先独立确认，再参考旧材料”，禁止画成“旧材料无用/被丢弃”。

# 2｜Text First｜文字是理解入口，资产只是辅助

HyperFrames 解释镜头默认：

> **文字负责定性；图标/生图资产负责快速识别、质感和IP感。**

## 2.1 视觉权重

推荐初始权重：

- 文字 / 结构：约 70–80%
- 图标 / 视觉资产：约 20–30%

不是面积机械占比，而是注意力优先级。

## 2.2 每个关键对象必须先有主标签

例如：

- `旧稿`
- `真实录音`
- `AI`
- `独立听写`
- `确认原话`
- `整理字幕`

资产可以跟在标签旁边，但不能要求观众先猜图标含义。

## 2.3 标签三层

### L1｜结论
最大、最清楚、停留时间最长。

### L2｜流程节点
观众无需旁白也能识别每一步是什么。

### L3｜补充说明
只解释状态或角色，例如：`先参考`、`暂不介入`、`后参考`、`已确认`。

L3 禁止抢 L2。

# 3｜Asset Role｜资产不是逻辑本体

生成资产只承担：

- 识别
- 材质
- IP完成度
- 空间层级

禁止承担：

- 精确文字
- 准确数字
- 完整因果
- 真实证据
- 复杂流程关系

一个资产如果删除后逻辑就看不懂，说明文字/结构设计还不够清楚。

---

# 4｜Connection Anchor Gate｜线必须真的连对

所有连接线必须从**对象的语义锚点**出发，到**下一对象的语义锚点**结束。

## 4.1 每个节点先定义 Anchor

```yaml
entry_anchor: top-center | left-center | custom
exit_anchor: bottom-center | right-center | custom
reference_anchor: side
```

竖屏纵向流程默认：

- 输入对象：底部中心输出
- 处理对象：顶部中心输入 / 底部中心输出
- 结果对象：顶部中心输入

## 4.2 禁止视觉近似连接

禁止：

- 线停在对象附近却没碰到对象
- 线穿过文字
- 线连接到装饰图标，而非逻辑对象
- 同一条线在动态中丢失锚点
- 对象移动后，线还留在旧位置

## 4.3 Dynamic Anchoring

对象移动时，路径必须跟随锚点重新计算或绑定。

**先更新节点位置，再计算Path。**

不得手写“看起来差不多”的固定坐标冒充动态连接。

---

# 5｜State Line Discipline

一帧里：

- 激活主路径：1条最清楚
- 非激活路径：降权
- 已失效路径：真正断开/退出
- 尚未发生路径：不提前出现

错误和正确路径如需共存比较，必须明确：

- 时间层级
- 空间层级
- 状态标签

避免观众误以为两条路径同时有效。

---

# 6｜Motion Verb Must Match Meaning

Tangyuan HyperFrames Motion Grammar 增补：

- `Seat`：进入正确位置
- `Connect`：建立关系
- `Disconnect`：关系失效
- `Reorder`：对象仍存在，只改变先后顺序
- `Delay/Gate`：对象仍存在，但延后介入
- `Route`：改走另一条路径
- `Patch`：规则写入系统
- `Verify`：确认事实/结果
- `Lock`：事实或版本锁定
- `Resolve`：停止动画并让观众读懂

**禁止用 `Swap` 代替所有“顺序变化”。**

# 7｜Director QA｜每个场景导出前必问

1. 不看图标，只看文字和线，逻辑成立吗？
2. 不听旁白，观众能说出主要关系吗？
3. 动画表现的是 Replacement、Reorder、Delay 还是 Route？和原始口播一致吗？
4. 所有对象是否仍然存在/消失得符合事实？
5. 每条连接线是否精确落到正确锚点？
6. 动态中对象移动后，路径有没有跟错位置？
7. 最后结论有没有比辅助资产更突出？
8. 删除所有装饰以后，这段仍然能讲清楚吗？

任一项 NO：不得 Director Lock。

---

# 8｜IP原则

> **IP感来自统一语法，不来自牺牲理解。**

长期统一：

- 深墨绿 / 暖白 / 暖黄 Voltage
- Tangyuan Node
- Deep Silk / Evidence Stage 等背景语言
- 统一字体层级
- 统一Motion Verb
- 统一资产材质

但所有IP资产必须退居文字与逻辑结构之后。
