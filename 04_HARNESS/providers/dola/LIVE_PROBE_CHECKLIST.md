# Dola Seedance 2.5 Live Probe — Minimal Checklist

Status: `REQUIRED_TO_UNLOCK_R1`

This is a **provider capability probe**, not a generation benchmark and not a new Human Gate.

Open the Dola video-generation surface used for production and record only the facts visible in the current account/UI.

## Minimum evidence

1. **Model label**
   - Is the selected model explicitly `Seedance 2.5` / `Dreamina Seedance 2.5`?

2. **Duration choices**
   - Record every visible duration option exactly as shown.
   - Do not infer missing durations from Seedance engine documentation.

3. **Reference mode**
   - Can one image be uploaded as the literal first frame?
   - Is there a separate multi-reference / multimodal mode?
   - Record any visible reference-count limit.

4. **Aspect / resolution**
   - Record visible aspect-ratio and resolution options.
   - If first-frame mode locks aspect ratio automatically, record that instead of forcing a dropdown value.

5. **Audio behavior**
   - Is audio always generated, optional, or disabled?
   - If there is a toggle, record its exact current setting.

6. **Output behavior**
   - Watermark/branding visible?
   - Download option visible?
   - Any quality/original-download choice visible?

## Evidence format

One screenshot of the model/settings area is preferred if it contains the above fields. If settings are split across panels, use the minimum number of screenshots needed.

## R1 unlock rule

R1 may move from `BLOCKED_ON_PROVIDER_DURATION` to `READY_TO_RUN` when we can bind:
- confirmed Seedance 2.5 model;
- one exact Dola-supported Precision duration;
- one exact image/K0 input method;
- equivalent audio/aspect/resolution settings for both Legacy and Lean variants.

## Excluded

Do not use temporary identities, repeated account deletion/recreation, quota cycling, verification bypass or other access workarounds as part of this probe or benchmark.
