# CASE_001 — TIMELINE.md

> 这里只记录 Reference Source Clock。未来 Target 不复制这些秒数，而是把关系重新绑定到新 Script 的 Moment / Selection / 实际 aligned delivery。

## 0.00–0.50 · Cold-open attitude

- Picture：普通 Presenter，普通房间，大标题抢占第一视觉。
- Camera：固定正面近/中近景。
- Speech/Caption：问题立即开始。
- Viewer Function：先给态度和 stop-scroll，再完全建立解释模板。

## 0.50–2.90 · State the exact puzzle

- Topic：顶部持久问题板进入。
- Host：直视镜头，手已经参与前景表演。
- Caption：同步复述问题。
- Audio：连续讲话。
- Function：无需背景铺垫，直接理解核心 puzzle。
- Transfer：Target 的 `Moment.question` 必须足够早，Persistent Topic 同步可读。

## 2.912–5.088 · Anticipation pause

- Audio：约 2.176s 近静音。
- Picture：Presenter 继续留在画面。
- Action：后段 Hand 向 Lens 运动。
- Function：把语义悬念交给视觉 Reveal。
- Transfer：停顿本身是设计关系，可保留“功能”，但新片时长可根据新表演重新决定。

## 4.80–5.60 · Occlusion handoff

- Action：Hand fills lens。
- Identity：普通 Persona → 新 Persona。
- Camera：底层关系保持一致。
- Function：低成本完成主题驱动的身份转换。
- Transfer：可换 Costume / Effect，但必须保留“Premise motivates Persona Shift”。

## 5.60–7.90 · Persona established

- Host：新 Persona 已经成立，但仍在旧空间。
- Performance：眼神和头部成为主要 Facial Channel。
- Function：先让观众接受“现在是谁”，再换 World。

## 8.00–8.50 · Chapter interrupt

- Effect：全屏 broadcast/glitch 类 interrupt。
- Function：切开 setup 和正式 explanation。
- Transfer：形式可换，但稀有、强、短的章节标点关系值得保留。

## 8.60–17.0 · Main visual system enters

- World：进入稳定主场景。
- Topic：Persistent Topic 返回。
- Caption：Live Caption 高频替换。
- Host：固定正面构图；短 Hand / Head / Eye Beats。
- Semantics：确认问题价值 → 开始第一层重构。
- Function：把 curiosity 转成可连续推进的 explanation engine。

## 17.0–29.0 · First category reframe

- Semantics：重新定义关键对象/状态，给出第一层决定性答案。
- Caption：Definition → Alternate Label → State Change。
- Performance：18.4 / 21.8 / 27.4s 附近有明显强调。
- Camera：固定；尺度变化来自 Subject / Hand。
- Function：第一次真正改变观众原先的分类方式。

## 29.0–49.0 · Constraint comparison / escalation

- Semantics：从“它是什么”进入“现实约束与比较难度”。
- Caption：持续 1–2 行替换；Topic 不变。
- Performance：31.6 / 33.8 / 36.2 / 39.8 / 42.6s 附近出现对比、框定、手势和头部变化。
- Function：每个新例子关闭下一层漏洞，但无需切换视觉世界。

## 49.0–69.0 · Usability / consequence turn

- Semantics：从拥有/获取，转成能否真正成立、使用或避免后果。
- Performance：56.8 / 60.4s 附近双手强调明显。
- Function：在画面基本不换的情况下改变论证轴，提供 Narrative Novelty。

## 69.0–83.6 · Summary → cost escalation

- Semantics：总结为什么整个 shortcut 不成立，再把代价/收益错配推向幽默。
- Performance：73.8 / 78.6 / 82.4s 动作更强。
- Function：从“讲道理”进入“荒诞感/娱乐性”。

## 83.6–100.4 · Final obstacle stack

- Semantics：继续叠加最后约束。
- Picture：不再引入新场景；依赖 Caption 与 Performance 继续推进。
- Function：让强度继续上升，同时保持稳定人设。

## 100.4–108.50 · Payoff / Punchline

- Performance：101.4s 左右为全片最强运动峰值之一；103.6s 左右继续出现近距离 Hand / Lean 强调。
- Semantics：把前面推理压缩成最后 binary / punchline。
- Caption：末段短句阅读节奏更快。
- Function：语言峰值与身体峰值共同结束视频。
