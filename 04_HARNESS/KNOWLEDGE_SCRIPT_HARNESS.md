# KNOWLEDGE_SCRIPT_HARNESS v1.0

状态机：`RAW → SOURCE_LOCKED → CONTRACT_LOCKED → INSIGHTS_LOCKED → HOOK_LOCKED → STRUCTURE_LOCKED → DRAFTED → EVALUATED → PATCH(max2) → HUMANIZED → FINAL_QA → SCRIPT_LOCKED`

1. Source Analyzer：先理解原始内容真正解决的问题，不立即写Hook。
2. Contract Locker：锁受众、平台、讲述关系、核心观点、Must Keep、因果链、目标时长、可重排表面结构。
3. Insight Miner：提炼核心观点、支撑观点、信息差、记忆点、用户获得什么。
4. Hook Director：3–5个候选；只包装核心观点，不发明新主题；正文必须兑现。
5. Structure Architect：允许轻倒叙/价值前置，但必须保持因果链。
6. Spoken Draft Writer：第一稿直接按时长预算写，不默认先超长再暴力压缩。
7. Evaluator：原意20、因果20、受众10、可执行10、留存15、口语10、记忆5、人称5、时长5。Hard Gate：观点漂移、因果断裂、超硬时长、人称漂移、Hook不兑现。
8. Patch Editor：只修Evaluator指出位置，默认最多2轮。
9. Humanizer：只优化口语和停顿，不新增观点/改结构/重新膨胀时长。
10. Final Gate：通过后锁稿。

五条最高规则：
- Source Before Hook
- Logic Before Retention
- Locked Means Locked
- Patch, Don't Rewrite
- Budget Never Regresses
