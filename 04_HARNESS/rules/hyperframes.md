# Rules｜HyperFrames Logic Motion v1.0

> HyperFrames的职责是让复杂逻辑“发生在观众眼前”，不是把知识排成PPT。

## Use When
优先用于：顺序、因果、错误→修正、状态变化、工作流、循环、规则进入系统、多步骤机制、变量变化导致结果变化。

不强行用于：普通标题、DAY、数字强调、CTA、常规字幕、简单标签/截图卡。

真实Evidence先展示真实素材，再用HF解释关系。

## Teaching Truth First
每场先回答：
1. 观众必须明白什么？
2. 最容易误解的关系是什么？
3. 删掉文字后，哪个变化仍能表达逻辑？
4. 最终必须记住什么视觉关系？

## Development Is Teaching
旁白讲到哪里，画面发展到哪里。禁止前25%把全部信息摆完、后75%只漂浮等待。

## Anchor + Variable + Consequence
复杂解释优先定义：固定锚点 / 真正变化变量 / 变化后结果。

## Signature Move
每场只允许一个真正的大逻辑动作，例如换位、断线重连、因果链生长、Camera Journey、状态同步、规则注入、产物Reveal。

## Fail Gates
- Slideshow：内容过早全部出现
- Screensaver：所有元素各自漂浮
- Card Wall：所有概念都变成同款圆角卡片

出现任一项不得Lock。

## Portrait & Hierarchy
- 1080×1920原生竖屏
- 流程优先纵向堆叠
- 主视觉约40%–60%
- 同时主焦点≤2
- 三层深度：Background / Midground / Foreground
- 一场只允许一个主强调色时刻
- 结论阶段允许真正静止

## Tangyuan Default Skin
默认起点：深墨绿黑 `#111511`、暖白 `#F1F0E8`、暖黄 `#FFD54A`，语义Correct/Error克制使用。禁止无意义紫蓝AI渐变、赛博HUD、PPT后台感。
