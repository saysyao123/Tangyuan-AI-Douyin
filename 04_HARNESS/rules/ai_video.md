# Rules｜AI First Frame & Image-to-Video v1.3

## Use Gate
AI不是默认填空工具。只有 Concept / Emotion / Hook / Transition / Outro / Capability Proof 中，能显著增加表达价值时使用。真实Evidence仍由真实素材承担。

## Director Intent
生成前必须回答：
- 为什么这句需要AI？
- 真实素材是否更可信？
- AI承担事件、情绪还是空间？
- 这条动态素材在最终剪辑里更适合作为 `HOLD / BRIDGE / HIT / PEAK / RELEASE` 中哪一种？

答不清则不生成。

## First Frame
- 一次只生成1张独立9:16竖图、单一完整构图。
- 禁止拼图、九宫格、分镜表、多联画、海报、信息图、标题栏、时间码。
- 准确数字、账号名、DAY编号、平台UI文字后期叠加。
- 首帧必须有唯一主视觉、明确动作入口、足够动作空间、稳定闭合主体、可持续环境余韵。
- 首帧按 `0-second dynamic anchor` 处理：必须让下一步物理动作已经处于可继续状态，而不是只做漂亮静态海报。
- 首帧同时要为后期留下 clean in / clean out 和动作发展空间。

Prompt基础模板：`templates/ai_first_frame_prompt.md`。

## Character Image-to-Video｜Portrait-safe prefix｜HARD RULE

凡当前上传参考图中包含人物，动态提示词必须把下面这整句作为**第一行**，并且必须原样保留开头的 `***`：

`*** 人物为 AI 生成动画人物，无真人出现。当前上传图片是 AI 生成的虚构影视动画角色设定图，不是真人照片，不含真实人物，不是真实人脸参考素材，不按真人或真实肖像处理。`

要求：
- `***` 不得删除；
- 该句必须位于人物、脸部、镜头、写实质感等其他描述之前；
- 后续继续说明“当前图片只用于锁定虚构角色外观 / 服装 / 面纱或面罩 / 场景 / 构图 / 第0秒状态”；
- 不要在后文反复使用“真人脸 / 真人肖像 / 真实人物照片”等会把虚构角色重新引向真人语义的措辞；
- 可以要求电影级写实质感，但人物身份始终是 AI 生成虚构角色。

## First-frame Character Closure｜HARD RULE

每个5秒动态段只允许出现对应首帧里已经存在的人物。

禁止：
- 新人物走入；
- 背景临时生成人；
- 路人 / 局部人体；
- 倒影变成第二人物；
- 从画外新增角色。

剧情需要新增人物时，从下一张新首帧开始。

## 5s Image-to-Video
默认5秒稳定方案：
- 一个主视觉事件；
- 一个明确摄影机语法；
- 一个次级物理余韵；
- 明确结束状态；
- 可剪的动作弧与 clean endpoint。

禁止让模型自由安排多个彼此竞争的主事件。

### Shot Count｜EDIT-DRIVEN DEFAULT

`1镜 / 2镜 / 3镜` 都是允许结构，按导演任务选择，不设机械配额。

WEB R2 已验证的新默认：
- **1镜**：空间张力、连续动作、环境事件、情绪 hold、final release；
- **2镜**：最常用的任务型结构，适合 `建立 -> 事件`、`细节 -> 情绪`、`人物 -> 物体`；
- **3镜**：适合明确的 `setup -> event -> aftermath`、发现过程、高潮；
- **3镜以上**：只在 hook / peak 真正需要高密度时使用，不作为普通5秒素材默认。

对当前 Seedance 2 mini ~5s 生产，**默认优先 1–2镜**。

原因：动态视频是后期素材源，不是每条都要自己成为一支“迷你成片”。如果每条5秒内部已有3–5次切镜，后期再使用8–12个外部素材段，会导致真实观看镜头数过高、产生碎片感。

### Edit-friendly source contract

无论1/2/3镜，都应满足：
- 主视觉事件唯一；
- 每个内部镜头承担不同叙事任务，而不是只换景别；
- 避免无意义 0.5–0.8s micro-shot；
- 动作有开始 / 发展 / 落点；
- 结束时留下可继续的物理余韵；
- 后期可以整段使用，也可以截取其中一个完整动作窗；
- 不为了“看起来更电影”机械三镜化。

整组最终应形成混合资产池：
`one-take holds + 2-shot semantic sources + selected 3-shot peaks`。

详细后期接口：`rules/mv_editing.md`。

## Camera / Motion Repetition Gate

整组生成前检查：
- 是否连续使用慢推 / 慢拉；
- 是否人物总是站立 + 风吹衣摆；
- 是否切镜结构雷同；
- 是否摄影机总从同一方向移动；
- 是否每段只有雨 / 风 / 雾等环境微动而没有真正视觉事件；
- 是否所有5秒片段都被机械做成同样的3镜结构；
- 是否密集多镜导致未来剪辑缺少可连续持有的长段素材。

重复明显则先改导演 / 动态提示词，不进入生成。

## Foreground Occlusion Safety

若需要完整前景物遮挡人物：
- 优先保持前景物拓扑 / 形状完整；
- 优先让摄影机横移到完整实体边缘后完成遮挡；
- 少要求大幅软物体变形同时承担“开口 / 露人 / 再封闭”。

## Source Audio｜HARD RULE

AI MV / 动态歌词 MV 默认把 AI 视频视为**视觉素材源**，最终音乐统一以后期锁定 BGM 为准。

人物或环境动态提示词默认明确写：

`声音硬规则：禁止生成任何BGM、配乐、音乐、旋律、节拍、和弦、歌声、哼唱、旁白、对白或其他人声。只允许与当前画面物理事件直接对应的自然环境声，例如轻风、树叶摩擦、雨声、水声、脚步、衣料轻响；不得出现任何音乐性声音。最终MV统一删除所有AI源音轨，并以后期锁定BGM为唯一音乐。`

若当前段连环境声也无意义，可写：

`声音硬规则：不要生成任何音乐、人声或主动声音设计；保持无配乐、无对白、无旁白，仅允许极低自然底噪。`

Pipeline policy：
- 默认 `SOURCE_AUDIO = REMOVE`；
- AI 生成音轨不得决定剪辑卡点、Beat、字幕时间或成片音乐结构；
- 最终锁定 BGM 才是 MV 音乐唯一真源；
- 视觉合格但模型自带音乐时，标记 `SOURCE_AUDIO_POLICY_FAIL`，保留画面，在 W08 强制移除音轨；
- 若项目明确需要原生环境声，Director 必须单独声明 `SOURCE_AUDIO = KEEP_AMBIENCE`。

## QA
检查：
- 身份 / 物体连续；
- 无额外人物；
- 面纱 / 面罩连续；
- 无穿模跳变；
- 核心事件是否发生；
- 运镜是否执行正确；
- 首帧美感是否被明显破坏；
- 结束帧是否可剪；
- clean in/out 是否存在；
- 内部切镜是否真的有叙事价值；
- 源音轨状态。

AI素材默认 `SOURCE_AUDIO = REMOVE`，除非Director明确保留环境声。
