# Rules｜Visual Core v1.0

> 权威范围：跨工具视觉职能、字幕/对齐、镜头纪律、真实证据。具体美术参考可按需读取 `05_IP_ASSETS/VISUAL_SYSTEM.md`，但不得覆盖本文件硬规则。

## Canvas
- 9:16 / 1080×1920 / 默认30fps。
- 程序化视觉从一开始按竖屏设计，不先横屏再裁。

## Visual Function
- Evidence → REAL
- Complex Explanation → HyperFrames优先
- Simple Utility → Remotion / 简单程序化
- Concept / Emotion → AI按需
- Capability Proof → REAL OUTPUT

## Text & Alignment
- 所有文字、数字、图标在所属容器内必须上下左右视觉居中，除非Director明确要求其他对齐。
- 小到手机端不可读、且与字幕重复的文字默认删除。
- 字幕负责完整语言；视觉节点/标签只负责关系，不抄整段口播。
- 禁止文字出框、缺字、被平台UI遮挡。

## Subtitle Default
- Noto Sans CJK Medium（可用时）
- 常规约48px
- 白色正文 + 暖黄关键词 `#FFD54A`
- 轻阴影 / 局部Soft Scrim
- 一行优先，最多两行
- 语义块出现，不逐字弹跳
- 字幕底/容器若存在，文字必须在其中上下左右居中

## Motion
- 一个镜头一个主方向。
- 允许稳定推进/拉远/固定轴Zoom/单向位移。
- 默认禁止呼吸Zoom、随机漂移、反复摇摆、无语义浮动。
- 摄影机运动只有在能解释关系时才使用。

## Evidence
- 高清原图承担放大、特写、数字证据。
- 低清录屏承担操作/页面运动，不高倍放大。
- 真实数字来自真实截图或明确后期文字。
- AI/HyperFrames不得重绘“看起来像真的”平台证据。

## Anti-Homogeneity
连续第三个语义段检查镜头语法重复；优先改变讲法/景别/空间关系，不随意更换整套色彩字体体系。
