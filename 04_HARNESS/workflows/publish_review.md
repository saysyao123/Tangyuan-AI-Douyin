# Workflow｜Publish, Review & Rule Upgrade v1.0

## Responsibility
完成发布包、记录真实数据、把观察沉淀成实验；只有满足证据门槛时才升级长期规则。

## Publish
按需读取 `05_IP_ASSETS/PUBLISH_SYSTEM.md`。
输出：标题、简介、封面文字、标签、置顶评论、发布时间建议。

## Performance Review
按真实发布时间记录：
- 1h
- 3h
- 24h

重点：Views / Likes / Comments / Favorites / Shares / Profile Visits / New Follows / Followers Before-After / Completion / Avg Watch Time（可见时）。

主指标：每1000播放新增关注 = 新增关注 ÷ 播放 × 1000。

## Separate Production From Performance
- 制作稳定 ≠ 平台有效
- 好看 ≠ 涨粉
- 单条结果 ≠ 长期规律

## Rule Upgrade
使用 `knowledge/PROMOTION_POLICY.md`：
- 制作稳定性可升级 `PRODUCTION_VALIDATED`
- 内容表现规律必须重复真实数据验证后才可升级 `PERFORMANCE_VALIDATED`

## Output Contract
- Publish Package
- Metrics Record
- Experiment Record
- Lessons
- Proposed Rule Change（如有）
- Rule Decision：`NO_CHANGE | EXPERIMENT | PROMOTE | DEPRECATE`
