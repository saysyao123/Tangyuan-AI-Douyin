# VIDEO_PRODUCTION_HARNESS v0.9

1. Script Lock：进入视频前锁稿，视频不得反改核心观点/因果/人称/时长。
2. Evidence First：先列真实截图、数据、结果、工具界面、前后对比，再决定AI视觉。
3. Director Plan：每段明确叙事任务、必须画面、核心动作、景别/视角、摄影机语法、环境事件、视觉记忆点。禁套模板。
4. Visual Strategy成本优先：真实截图动态裁切 → Remotion动态图形 → 动态PPT/数据 → AI图片 → AI视频 → 高成本复杂AI视频。
5. Audio：本人真实声音为主，BGM低存在感或不用，音效只做信息强调。
6. Quality Gate：前3秒问题/结果、画面支持口播、证据可看清、字幕易读、有视觉记忆点、不过度炫技、生产时间可持续。
7. Publish Package：最终视频、封面、标题、简介、可选置顶评论、发布前粉丝基线、METRICS。
