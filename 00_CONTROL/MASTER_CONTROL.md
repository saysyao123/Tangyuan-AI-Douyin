# 汤圆AI实战｜项目总控 MASTER_CONTROL v1.0

> 生效日期：2026-08-15。若每日聊天临时想法与本文件冲突，以本文件已锁定规则为准，除非总控明确完成规则升级。

## 原始目标

使用现有抖音账号「汤圆AI实战」进行一次公开AI自媒体实战实验：从37粉开始，30天冲击1000粉。真正目标是跑出可持续涨粉内容模型、建立汤圆IP、建立每天可稳定运行的AI生产工作流，并把真实测试/失败/复盘沉淀为SOP、Skill和长期资产。

## 第一季公开故事

**《30天AI重做我的37粉抖音号》**

- Day 0：37粉
- 30天目标：1000粉
- 公开重要播放、涨粉、失败与调整
- 跑通的方法公开
- 踩坑也公开
- 不伪造亲测

## 账号定位

账号：**汤圆AI实战**

> 一个非程序员、长期真实使用AI的人，把工具和方法亲自跑一遍；跑通了给方法，踩坑了也告诉你。

受众：知道AI重要、但还没真正把AI稳定用起来的普通人。

第一季主线：AI内容创作 / AI视频 / 自媒体运营。

## IP人格

非程序员、AI重度真实使用者、实验型、愿意公开失败，以可复现结果和真实判断建立信任。

固定表达：**真实过程/踩坑/冲突 → 原因判断 → 实际修正 → 可复制结论**。

## 出镜与素材

前期不强制真人露脸；使用本人真实声音；AI尽可能负责视觉、字幕、动态图形、PPT与合成。每条实战视频原则上至少有1个真实证据点。旧视频暂不大规模删除/隐藏，作为历史实验和定位混乱的真实证据。

## 内容边界

优先：普通人真实问题、本人实测/可验证、可执行方法或明确判断、强化汤圆AI实战关注理由。

非主线：纯AI新闻搬运、只讲模型参数、无实际使用价值的技术八卦、未实测却包装成亲测、与IP无关的随机主题。

## 资讯规则

热点进入主视频前必须回答：**这个变化对普通人今天到底有什么用？**

优先：热点/新工具 → 汤圆真实测试或明确研究 → 普通人怎么理解/怎么用。

## 每日选题来源

A. 历史真实项目池（最高优先）  
B. 目标用户问题池  
C. 过去24小时热点池

建议非硬性比例：60%真实项目、30%用户问题、10%重大热点。

## 第一季核心叙事

37粉 → 分析旧账号 → 重做定位 → 选题 → AI生产 → 发布 → 数据 → 失败/成功 → 复盘 → 修正 → 跑出模型 → 冲击1000粉。

## 节奏

- 默认每天1条
- 常规制作：20:00–23:00
- 默认D日晚制作、D+1日发布
- 第一阶段发布锚点：18:20
- 前14条尽量不同时改变内容模型和发布时间

## KPI

主指标：**每1000播放新增关注 = 新增关注 ÷ 播放 × 1000**。

辅助：播放、完播、点赞、评论、收藏、分享、主页访问、内容类型稳定性。

## 口播

使用 `04_HARNESS/KNOWLEDGE_SCRIPT_HARNESS.md`。

最高规则：Source Before Hook / Logic Before Retention / Locked Means Locked / Patch, Don't Rewrite / Budget Never Regresses。

## 视频生产

口播锁定后，画面服务口播，不得反向破坏逻辑。优先真实证据截图、Remotion动态图形、动态PPT，再考虑AI图像/视频。若约3小时内无法稳定完成，则不适合作为默认形式。

## 每日新对话范围

只负责当天一条视频从复盘到可发布成片；不重新讨论已锁定位。只有关键缺口会明显改变当天结果且无法从仓库/工具/合理假设解决时才提问，一次一个。

## 总控与每日执行

总控：项目管理、归档、状态更新、选题去重、数据维护、规则升级、周复盘。  
每日执行：只生产当天一条视频，结束生成 `DAY_XX_HANDOFF.md`。
