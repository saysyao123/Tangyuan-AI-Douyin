# 从热议到中文成片

执行顺序：启动检查 → 新闻证据 → 口语稿 → 逐句配音与锁定 → DIRECTION → 画面配置 → 混音 → 渲染 → 验收 → 交付。尽量在同一任务内完成。已有授权和偏好无需重复询问；确实缺账号、不可替代原素材或必要决定才请用户协助。

## 选题与证据

默认三条主题，情绪有起伏：惊险事件用克制口吻，传言与回应讲清反差，轻松话题用于收尾。查 X、YouTube、新闻、当事人/品牌公开原文与采访。搜索结果只是线索，必须读正文并确认发布日、事件日、数字及原话。片中只出现简报已经确认的事实。

建立事实表：fact id、一句事实、verified/unverified、原始链接、核实说明、日期。重要数字回官方资料核对；查不到就删除该数字或明确未证实。争议性消息优先找原发布者和直接回应。只有转载截图时注明“报道转引”，不要写成已读到原推。

用户没提供X账号或授权时，记“没读到：未提供账号/入口”；来源已经访问且当天没有内容才记“没更新”。不能虚构X互动数、收藏、评论用户名。使用X原推时存完整 status URL、英文原文、真实作者、关键句和中文翻译；`tweet`画面高亮原文中的实际片段。

实拍视频为主，每句配独立、匹配语义的画面；尽量找相关人物同框，但不得从同框推断关系。下载公开原视频，可使用 yt-dlp；若需要登录才能取到，由用户提供获授权素材。不处理登录绕过。保留出处、素材日、原分辨率、哈希、起止秒和裁切参数。

原字幕/台标在素材层裁掉，别误把实物上的品牌标识当电视台标。镜头不同区间不交叠，不能循环同一段填满旁白。裁切保护头部和双人关系；低清资料如实标注，1080p输出不能宣传素材全高清。儿童正脸不用。截图少量点缀，用于阅读官方原文。

## 写稿、配音与时间线

按 `prompts/DOUYIN_NARRATION.md` 写第一版，Humanizer-zh 清理播报腔后逐项和事实表对照。不要让去AI腔删除“未证实”“据采访”等必要限定。每条字幕一整句，短句单独合成；模型不负责生成新事实。

配音默认沿用已交付的 `Kokoro-82M-v1.1-zh / zf_001`，speed 0.92，云端CPU，免费，不克隆当事人。先改善文案、标点和停顿；不能把模型换名就当口语问题已解决。可测试小幅速度变化，听感未验收的新声线须记候选。原稿改了，对应音频必须重新生成；不能沿用旧句WAV。运行器通过文字、声线、速度、模型版本和输入音频哈希隔离缓存。

每句测出实际 speechDuration，加自然段间停顿后累计 start/end。第一句3秒内讲完；超限重写钩子，禁止吞字硬加速。最终总时长<=300秒。只有实际音频锁定后才能把导演时间标成正式。输出字幕整句，不截英语单词，最多3行。

## 方向与画面

每期在生成镜头前写 DIRECTION：日期与主题、真实来源、三条情绪、字体/颜色/位置、首帧、每句画面、裁切、截图阅读、声音、例外。默认沿用旧一期已获肯定的视觉，不重启整套设计。

设计token：纸白 `#fafaf8`、墨黑 `#0a0a0a`、安全橙 `#FF6B35`；标题 Noto Sans CJK SC Light 300，字幕 Medium 500，1080×1920，边距56px。第一帧真实当事人照片和大标题，人物图仍要核对身份。技术自检允许原创测试图，正式新闻不能把技术占位画面当素材。

将已审核内容写入 episode JSON：本期来源/facts、公开素材/assets、中文 rows、direction、brief 和 editorial_review_complete。每行 type 为 cover/video/image/tweet/end；kind 为 fact/claim/comment；事实/传言行要引用 fact_ids；video 指定 asset/start/end/crop；end 有评论问题。格式以 examples/smoke.json 和历史迁移配置为准。自动验证元数据不能证明编辑写下的“已核实”是真的，制作助手仍须读来源。

代码生成真实React画面，用暂停的GSAP时间轴，Playwright按30fps调用 `seek(t)` 截帧，FFmpeg生成H.264/AAC。音乐为原创轻器乐，真实旁白作为sidechain信号自动压低BGM。新场景先短试跑；通过技术与视觉检查后接着完成整期，不无故新增用户确认关卡。

## 去敏与恢复

未给去敏名单时默认普通版；给了名单后在旁白、字幕、标题、原文卡、截图、人物和反射/海报等背景里全链路去除。仅文字替换不等于去敏完成。用不同的episode id和输出目录，不覆盖原片；先审核新视觉再渲染。仍可能识别人的图像须替换为与叙事相符的证据/场景，不能只糊名字。

代码在GitHub；每期原素材、逐句音频、计划、DIRECTION、来源与检查记录需保存工程ZIP。渲染帧缓存按计划、媒体内容、字体、页面和音频哈希隔离，出错可续跑；输入变了自动换缓存。已通过的选题/素材不因渲染故障全部重做。全片通过QA后才叫完成；导出了文件但还没看图/听感，状态写 exported_awaiting_review。

本运行器一次处理一条片，不在同一目录并行渲染多期。原始影片和模型不入Git，成片和工程包不依赖云端任务临时空间长久保留。
